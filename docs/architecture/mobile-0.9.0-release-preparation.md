## 拟发布更新说明

界面更轻盈，浏览与管理更清晰。

- 首页、动态、设置和消息页采用柔和背景，内容区更清晰，顶部页签更简洁。
- 个人中心与主题管理入口更容易辨认，通知和私聊列表更舒适。
- 支持主题中的独立发言身份，并优化相关作者信息展示。
- 改善楼层定位、主题标签选择与私密邀请链接的使用体验。
- 改进正文链接、对齐操作和站内复制链接，减少编辑时的干扰。
