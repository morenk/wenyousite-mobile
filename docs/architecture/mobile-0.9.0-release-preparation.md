# Android 0.9.0+98 发布准备

负责人于 2026-10-07 明确授权合并本轮视觉分支并准备正式版。版本沿用项目正式版本节奏准备为 `0.9.0+98`：已只读核实 `v0.8.0` 对应 `0.8.0+97`，线上 `/meta` 推荐 build 97；新包使用 build 98。此记录不表示正式上传、说明发布、dev → main 晋级或 Tag 已获授权或完成。

## 拟发布更新说明

界面更轻盈，浏览与管理更清晰。

- 首页、动态、设置和消息页采用柔和背景，内容区更清晰，顶部页签更简洁。
- 个人中心与主题管理入口更容易辨认，通知和私聊列表更舒适。
- 支持主题中的独立发言身份，并优化相关作者信息展示。
- 改善楼层定位、主题标签选择与私密邀请链接的使用体验。
- 改进正文链接、对齐操作和站内复制链接，减少编辑时的干扰。

说明按 `v0.8.0..dev` 的已合入范围准备，尚未写入或确认后台的 build 98 文案。正式发布前需核对精确版本的已确认 revision 与实际签名制品，不能复用 build 97 的说明确认。
