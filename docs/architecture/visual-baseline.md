# 移动端视觉基线

移动端视觉唯一规范是 Foundation v1.2.1 的 Flutter profile 与仓库内 Token。现行页面使用纯白画布、轻量分隔、12/24dp 响应式外边距、600dp 最大内容宽度和不小于 48dp 的独立触控目标；列表容器与列表项占满分配列，只有消息气泡、标签、徽标和紧凑操作可按内容收缩；柔粉只作为品牌与状态强调色，不作为整页背景。

四个主导航固定为“首页 / 动态 / 消息 / 我的”，中央粉色按钮是全局“发布”；搜索从首页与动态顶栏进入，不占主导航分支。发布按钮点击后选择“发布主题帖”或“发布动态”，当前频道只影响推荐顺序。开发 API、契约版本和环境连接提示不得作为正常用户首屏内容。

连续内容使用留白和分隔线表达层级；卡片只用于真正独立的概览或操作模块。纵向列表的行、卡片和状态模块必须占满页面边距内的可用宽度，并在宽屏收束到统一最大宽度，绝不能由标题或正文长短决定自身宽度；标签、等级徽标等紧凑信息例外，必须按内容收缩。长篇 Markdown 正文默认约 17sp、1.8 行高和轻微字距，标题、引用与分隔线只建立阅读层级，不承担大面积装饰。文字创作页把提交放入紧凑顶栏，低频草稿操作按需展开，纵向空间优先分配给随窗口增高的正文画布，不在底部堆叠整宽动作按钮。动态详情图片只保留页面级外边距，360dp 视口下舞台宽 336dp，标题和正文另有内边距。内容图始终 `contain`，裁切封面必须能进入完整原图。

仓库不保存手工截取的设备页面作为长期设计事实，避免旧导航、旧文案和临时环境提示继续误导实现。当前自动化视觉基线覆盖 Foundation 基础组件、动态瀑布流、首页文字主题卡、主题创作首屏、帖子全高编辑器与 `test/core/widgets/goldens/markdown_reading_360.png` 长文阅读样张；变更必须同时通过 360/400/600dp Widget 回归和 Foundation 门禁。对应文件位于 `test/**/goldens/`，由 Widget 测试生成并校验。
