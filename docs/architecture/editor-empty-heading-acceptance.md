## 已证实原因与候选范围

两处标题解析要求 `## `／`### ` 后至少有一个正文字符。工具栏建立空标题后，编码器会保存空标题标记，再读取时却把标记当普通文字；保存前的语义校验因此发现标题、文字不一致并拒绝保存。候选同时调整中立块解析和富文本行解码，承认合法空 H2/H3；空标题规范保存为 `##`／`###`，不添加假文字。

Quill 在行首收集选区样式时还会排除标题属性，导致空标题重开后的工具栏状态和回车分支误判。移动端读取实际行属性恢复标题状态；空标题回车继续交给 Quill 的常规标题命令。未关闭保存安全校验，未修改依赖缓存；不支持的对齐空标题仍按现有共享契约降级，不能以原始 Delta 静默激活。

本轮不调整正文对齐、引用间距、Foundation 视觉样式或后端格式协议。手动回车后恢复左对齐的需求仍由关联跨端切片处理。
