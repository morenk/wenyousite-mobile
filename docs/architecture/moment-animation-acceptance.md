## 行为与证据

- 列表统一经过 `MomentCoverImage`，GIF（包括 `animated=false` 但 `contentType=image/gif` 的旧记录）只允许 thumbnail；静态图片只允许 feed、thumbnail、medium。缺少派生图或失败显示占位，URL 与原图相同的候选也排除。

## 负责人设备复验

当前没有连接的 Android 设备，也没有代理查看过的 Debug 会话；自动化不能替代真机验收。

1. 使用专用账号分别查看发现、关注、搜索、个人主页和收藏的同一 GIF：正常封面、缺缩略图、缩略图错误时均静止。
2. 详情验证单图和多图；切图仅当前播放，滚到评论区后轮播停止，同屏主评论与楼中楼 GIF／动态表情都播放，离屏停止。
3. 打开全屏、切图、双击／捏合缩放、下滑／返回关闭；底层动画暂停，关闭后恢复。临时离开页面、锁屏、切到其他 App 再返回核对恢复。
4. 断开图片源制造动画失败，确认静态预览和“重试播放”；切图、全屏进退、前后台不自动重试。恢复网络后明确重试。
5. 保存 GIF 后在相册确认仍有多帧；主图失败不能以静态预览冒充保存成功。收藏当前动态／评论图片后确认来源正确。
6. 回归 100×50 静态图片、横竖图、动态发布编辑器和主题帖；核对原比例、静态图片尺寸与原路径一致。
