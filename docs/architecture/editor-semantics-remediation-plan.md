## 目标与边界

同一正文在读取、编辑、剪贴板、草稿、提交与重开时保持文字、真实空行、块归属、列表父子关系和原子节点身份一致。普通正文／引用一次回车只换一行，手动回车产生独立排版段并恢复左对齐，自动折行保持整段方向；标题和列表保留常规行为。

继续保存共享 Markdown，不引入移动端私有持久化格式，不批量改旧帖，不改 Foundation、编辑器依赖或接口模型。无法表达的历史结构保留原文并阻止有损覆盖。共享语义变化必须经 VPS 固定契约交接；移动端不修改后端只读镜像。

## 必须区分的四种空状态

1. 用户主动留空行：真实正文结构，数量必须保存。
2. 空标题／空列表项／空引用：合法编辑结构，按共享规则保存；自身不使空正文变为可发布正文。
3. 光标待输入样式：尚无对应正文，例如空行暂选对齐；仅按既有契约保留会话状态，不伪造文字或非法标记。
4. Markdown 语法分隔：保证相邻块不会串接；保留其结构作用，不能增加可见或可编辑空白行。
