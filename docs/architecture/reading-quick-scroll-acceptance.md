## 需求与范围

用户反馈：楼层／楼中楼单条正文很长或数量很多时，需要反复滑动才能到达下方。原反馈没有提供具体帖子或设备，本次按新增阅读导航能力实施，使用合成超长正文和多楼层场景验证，不声称复现了特定原帖。

主题详情作用于当前子贴正文与当前筛选、排序下的楼层；独立讨论作用于原楼层及当前回复。只在页面内保留导航状态，不增加阅读历史、跨子贴连续滚动、后端接口或后台自动发布。

## 使用方式

1. 主题顶栏在“定位最新回复”右侧点击“快翻”，底部出现独立工具栏；正文宽度不变，视口为工具栏腾出空间。独立讨论将快翻放在返回原楼层入口右侧。
2. 横向拖动滑杆，正文实时跟随；拖到最右端并保持按住时，继续跟随新增页和图片高度变化直到当前讨论末尾。往回拖时按当前范围微调，松手立即停止跟随，可以停在超长单层内部。
3. 点击“开头／末尾”定位边界；文字未全部加载时仅标为“已加载末尾”，加载失败可重试。
4. 位置提示使用实际可见的正文、楼层号或回复作者，不将作者筛选后的序号当成楼层号，不展示精确阅读百分比。
5. 点击“收起”回到常规阅读；编辑、筛选、切子贴、键盘出现和访问权限终止会关闭工具。底部发表、点赞等入口继续可用。

右侧细进度提示仅绘制，停止滚动 1.5 秒后淡出。它没有点击／拖拽命中区，不接管楼层正文和系统边缘返回手势。

## 实现约束

- Foundation 只读 Git 缓存已执行 `git fetch origin --tags`，最新正式版仍为 `v6.9.0`，依赖无需升级。
- 后端已从 5.18 同步到 `5.20.0-dev.20260909.1`，来源 `0ee2c0de1d9c570e495e778be6661b074b7a4bef`；2026-09-11 公网 `/meta` 一致。前置同步独立提交 `cce1602`，只新增封面媒体生成类型。
- 页面复用原 ScrollController、两屏缓存、保活和串行文字预取。渲染锚点只登记已布局对象；不主动创建全文布局或加载所有图片。
- 滑杆按像素阅读距离映射，普通拖动期间冻结范围，每帧合并更新；按住最右端明确进入末尾跟随，新布局完成后才推进；没有边界变化时不循环请求帧。离开末端时采用当前范围重新微调，松手后重新读取实际位置，不跟随后续分页自动前进。
- 首次懒布局将范围估大后，主阅读列表通过 `ReadingQuickScrollPhysics.adjustPositionForNewDimensions` 在布局内收紧映射，绘制前校正到手指对应位置，不先显示末尾再下一帧跳回。普通拖动不随估算增长扩张范围；校正结果用于松手和再次拖动，正文集合变化、阅读锚点尺寸变化或切换作用域时失效。此 Physics 只接到主阅读列表，保留原有滚动／下拉刷新规则，不影响内嵌滚动区域。
- 原始 Sliver 懒布局范围是估算值，图片也可能改变高度；快翻属于大致定位，首尾最多校正 12 帧，失败保留现状并允许重试。开关工具保留普通阅读位置，处于末尾时遵循视口变高后的合法边界。
- 用户快翻主动解除深链自动对齐；拖动正文、筛选变化、关闭和销毁会取消排队动作。组件不会持有跨页面进度。
