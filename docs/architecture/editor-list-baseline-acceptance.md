## 已证实的移动端原因与候选

`wenyouEditorTextStyles` 已为正文设置 Foundation 的 17sp／1.8 行高，却没有提供 `DefaultStyles.leading`。Quill 默认标记因此使用 16sp／1.15；自定义 builder 之前只覆盖颜色。Quill 将标记和正文顶部放在同一位置，两套字形与行框度量就造成基线偏移。发布态的列表标记一直使用 `spec.listMarker`，所以同一正文在阅读态没有这项默认值遗漏。

候选为 leading 显式提供共享 `spec.listMarker`，正文／标记统一字体、字号和行高。缩放后按实际数字和圆点字形测量最小标记栏宽度，保留既有间隔和嵌套缩进，避免句点换行或机械放大整列而挤占正文。主题创作与楼层／回复面板都消费同一入口；不改 Markdown、Delta、发布请求或保存校验。

视觉切片先 fetch Foundation 正式 tags，独立 `chore` 提交 `a4c2d73c` 固定 v6.10.0／`72f28500aee561cde3036a27699b5fc864bbe32d`。该版既有字体、排版数值与品牌资源保持兼容，版本与品牌资源回归 10 项通过；没有为本问题修改 Foundation 源码或上游 Quill。
