# 移动端架构加固验收

## 范围与结果

本轮覆盖会话与网络、账号草稿与幂等、查看者缓存、共享业务边界、长列表并发和架构门禁。保持现有产品范围、API Schema、数据库 v1、Foundation v6.9.0 与开发版本 `0.7.0-dev.1+94`，不包含正式发布、后端开发或真机代操作。

| 边界 | 已落地的约束 |
| --- | --- |
| 会话与网络 | 安全存储串行提交；请求与刷新绑定会话代次；旧会话响应、重试及退出不能覆盖新登录。 |
| 草稿与创建 | 动态按账号保存到 Drift；创建载荷与 UUID 原子落盘；待确认动态禁止修改，仅显式重试；主题确认与关联清理采用事务。 |
| 缓存与生命周期 | 只读投影统一依赖 SessionScope 与可见性版本；Token 刷新不清草稿；异步回写复核 mounted 与请求代次。 |
| 业务协作 | thread_feed 统一主题读模型、映射、卡片和公开分类目录；上传错误保留诊断与重试属性；通知筛选值与 Foundation 展示目录分层。 |
| 长列表与并发 | 通知、钱包和用户内容使用惰性 Sliver；游标不透明；迟到写入不覆盖刷新/筛选快照，角标重新校准。 |
| 工程门禁 | AST 导出链校验；35 条精确内部引用边冻结；900 行上限覆盖测试、工具及新增未暂存文件；十个大测试与检查脚本按职责拆分。 |

旧 SharedPreferences 动态草稿缺少可信账号归属，按本轮决策原样保留，不读取、恢复、迁移或自动删除。没有账号注销、共享数据批量删除、服务部署、正式签名或线上更新策略修改。

## 项目负责人真机清单

仅使用公网专用测试账号 A/B，复用负责人启动的 Debug 会话或安装本地 Debug APK。不得用正式账号或共享数据制造破坏性场景；失败时记录页面、操作顺序和安全问题编号，不复制 Token、私信全文或图片签名查询参数。

- [ ] 登录 A 后在列表请求/图片上传期间退出并登录 B；不得短暂展示 A 的通知、私聊、收藏、资料或草稿，旧错误也不得把 B 退出。
- [ ] 同账号正常会话刷新后，主题和动态编辑内容仍保留；重启应用仅恢复当前账号草稿，切回 A 后可恢复 A 自己尚未发布的内容。
- [ ] 新建动态填写文字并完成选图，退后台/退出编辑页/重启后检查文字、封面及顺序；成功提交后重进不得复活旧草稿。
- [ ] 在可控弱网下核对待确认动态：内容只读、离页只保留、恢复网络不自动发布；点击“重试确认”最终只有一条创建结果。主题保存/发布过程中重复点击也只形成一次创建。
- [ ] 仅在专用测试账号和明确金额下检查钱包待确认操作：输入空白或非法金额不能丢失原待确认金额，重试不产生第二笔同操作。
- [ ] A 拉黑/解除测试账号后，返回发现、搜索、用户、通知和私聊检查可见内容重新读取；主题创作草稿不受可见性刷新影响。
- [ ] 在首页、标签、主题创作/管理和用户内容中核对分类名称一致；图片上传失败时提示、问题编号复制与重试入口保持一致，不可重试错误不出现误导按钮。
- [ ] 长通知列表检查首屏、连续滚动、筛选、下拉刷新、分页、尾项删除与角标；空页仍有后页时可继续加载。快速切换筛选后旧操作结果不得覆盖当前栏目。
- [ ] 钱包流水、本人及公开用户的主题/回复列表检查末项可达、分页入口、返回位置、内外滚动协作；360dp 与放大字体下无溢出或不可达控件。

以上均待项目负责人反馈，不宣称本轮已经完成真机或视觉验收。涉及初始化、Provider 与全局状态的改动需要热重启；依赖变化后应重新启动 Debug 会话，不能只热重载。

## 仍保留的债务

`StateNotifier` 59 处、内部层引用 35 条、原始加载圆环 77 处按业务切片继续减少；700～900 行的文件仍会收到复审提示。Kotlin 插件迁移警告、正式升级安装、协作者权限、分类新投影和搜索分页等独立工作继续以 [当前计划](../../PROJECT_PLAN.md) 为准，不将本轮架构加固等同于所有产品缺口清零。规则详见 [依赖边界](dependencies.md)、[网络与会话](networking.md) 和 [持久化](persistence.md)。
