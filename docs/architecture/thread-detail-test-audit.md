# 主题帖内部测试审计与真机清单

审查日期：2026-08-23

## 1. 范围与基线

本审计覆盖广义主题帖内部：公开/私密详情、子贴切换与正文、楼层和楼中楼、主题内搜索、编辑器与图片、点赞、收藏、订阅、加油、举报、主题/子贴/成员管理和私密邀请。新建主题业务、首页/全站搜索列表本身、账号注销和管理后台不在本轮主范围内。

审计起点为 `dev@b919f901b35e4057a8939d0b5df65ba4d7f96085`。契约、公网 `/meta` 和后端 `origin/dev` 均为 `5.6.0-dev.20260823.1` / `82bdfc13e0388c0ca7193b58c1b00f1873cab469`，Markdown 契约版本为 3。起点全量 `flutter test --no-pub --concurrency=4` 共 1126 例通过；主题相关审计集合为 53 个文件、435 例。

## 2. 已有测试集评价

现有测试集的优势：

- 详情、楼层、楼中楼、编辑器、主题管理、成员、邀请、订阅、加油和举报均已有 repository、controller 或 Widget 测试，不是只覆盖成功页面。
- 分页请求代次、失效 cursor、迟到响应、幂等键、乐观锁、403/404 清空旧私密内容等高风险状态有较完整的单元回归。
- 320～600dp、文字缩放、语义节点和 Golden 覆盖了主要阅读与编辑布局。
- Markdown v3、骰子、提及、传送门和图片上传分别有协议、编辑器与媒体测试。

审计确认的主要缺陷：

- 多数页面测试在 repository 端口注入 Fake，缺少 Router → 页面 → controller → 生产 API 仓储 → 生成客户端 → Dio 的组合证据。
- 生成 DTO 的请求/响应 ID、主题/子贴归属、父楼层、回复目标、kind、幂等键和分页 cursor 负向矩阵不完整，错误数据可能被映射为可操作界面。
- 订阅状态曾使用详情中的成员投影作为 viewer key；普通登录用户该投影可能为空，切号后可复用前一账号状态。
- 加油弹窗只禁用按钮，没有阻止提交中系统返回；弹窗销毁会丢失在途幂等状态。
- 独立讨论曾允许已删除主楼层或回复暴露举报入口。
- 管理者页面测试夹具把当前账号写成楼主 ID，却同时声明 `isCurrentUserOwner=false`，掩盖楼主/协作者差异。
- 起点全量测试有一处非致命 hit-test 告警；默认配置不会让此类无效点击使测试失败。
- `thread_detail_page_test.dart` 和 `post_replies_page_test.dart` 体积较大，仍有较多 `pumpAndSettle`；这会降低失败定位速度，并可能把动画或未收敛异步任务误当作等待条件。
- 自动测试没有真实四账号、公网私密邀请、Android 系统返回/前后台、系统选图器和弱网联合链路；这些不能由 Fake repository 或桌面 Widget 环境证明。

## 3. 本轮自动化补强

- 订阅 Provider 以 `threadId` 为 family key，并观察稳定 `SessionScope`；viewer ID 只从当前会话派生，切号或退出后旧玩家订阅面板当帧隐藏并关闭。
- 加油提交中使用 `PopScope` 阻止系统返回；不明确失败后同金额重试继续复用原 `clientRequestId`。
- 主题、帖子、楼层和回复仓储在映射前校验可由 DTO 证明的 ID、kind、层级、关联和幂等事实；`hasMore=true` 时必须有非空 cursor，空响应不伪装成功；顶层楼层携带 `replyToPostId` 是后端允许的合法形态，不会因客户端过严校验被拒绝。
- 新增脚本化 Dio transport，覆盖真实 GoRouter、主题详情页面、生产 API 仓储 Provider、生成客户端和 Dio 的读取、错误拒绝、查询参数及楼中楼写入序列化。
- 已删除的独立讨论内容不再开放举报；错误、会话变化和管理页面补充对应 Widget 状态矩阵。帖子编辑器的子弹窗归属独立嵌套 Navigator，切号只移除捕获的编辑器外层 Route，不会误关同帧新开的业务页面，旧会话回调与提交统一 fail-closed。
- 修正不可能的协作者夹具；点击改为真实语义命中，并把后续 hit-test 告警提升为测试失败。
- 相关测试同时使用固定随机种子复跑，防止只在声明顺序下通过。
- 最终全量覆盖率诊断以固定随机种子执行，1172 例全部通过；全仓行覆盖率为 82.1%，主题帖相关模块分别为 threads 84.4%、posts 85.8%、social 81.4%、wallet 86.2%、reports 96.5%、search 72.3%、editor 87.1%、media 88.2%。其中 search 的相对低值是下一轮优先审查信号，不作为本轮完成门槛。

## 4. 仍需保留的测试债务

- 当前组合测试只选择关键读写链路，没有为每个 operationId 建立完整 UI 到 HTTP 的端到端用例；其余端点仍由仓储与控制器分层测试共同证明。
- 公网开发环境测试不自动制造限流，也不批量删除、注销账号或修改共享数据；`429` 只在本地注入测试。
- 覆盖率只作为诊断，不作为完成定义。高覆盖不能代替角色权限、响应关联和真机系统行为断言。
- 大型 Widget 测试仍应在后续纯测试重构中按阅读、写入、定位和管理场景拆分，并逐步把无界 `pumpAndSettle` 换成状态驱动的有限等待。
- 本文的真机清单必须由项目负责人在专用账号和指定测试主题上执行；未反馈结果前，不把公网真机项标记为完成。

## 5. 公网真机角色矩阵

准备四个专用账号：楼主、协作者、已标记玩家、普通局外人；游客通过退出登录获得。使用一条公开测试主题和一条私密测试主题。只修改测试主题和测试内容，不操作共享业务数据。

### 游客

- 打开公开主题，切换全部子贴，验证正文、楼层、短/长楼中楼、图片原图、骰子明细、提及和传送门。
- 使用主题内搜索定位主楼层和具体回复，再返回主题；验证不会循环跳转。
- 打开私密主题稳定路径，确认不泄露标题、成员或正文。
- 点赞、加油、发楼层等写入口进入登录，并保留原主题、子贴或帖子坐标。

### 楼主

- 编辑主题设置、默认正文和标签；创建一个非默认测试子贴，编辑、重排并只删除本次创建的子贴。
- 切换玩家标记，任命并移除测试协作者；每次操作后重新进入页面确认服务端事实。
- 私密主题刷新邀请链接，验证旧链接失效、新链接可预览并加入。
- 确认本人主题不显示自我加油和举报；不要删除整条测试主题。

### 协作者

- 编辑允许的标题、状态、标签、默认正文和非默认子贴。
- 确认不能修改可见范围、删除主题或任免协作者，但可以维护非楼主成员的玩家标记。
- 对普通楼层和回复执行允许的编辑/删除；只删除本账号本轮创建的测试内容。

### 已标记玩家

- 按各子贴发言策略发表楼层和楼中楼回复；编辑器验证图片、提及、骰子、草稿恢复与关闭后再打开。
- 验证 20 个骰子边界、上传失败重试、断网保留草稿且不会自动发布。
- 从更多操作退出玩家身份，确认发言权限和玩家订阅候选随服务端事实刷新；由楼主恢复测试身份。

### 普通局外人

- 点赞并取消、收藏并移动收藏夹、订阅官方更新和玩家发言，然后逐项恢复。
- 账号 A 打开玩家订阅面板时切换到账号 B，再退出登录；旧账号候选和开关必须立即消失，B 账号重新请求自身候选。
- 只执行一次主题加油，金额固定为 2 升；核对付款余额、主题累计和流水目标，不再用其他金额重复写账。
- 只举报预先指定的测试主题/楼层/回复目标；验证本人、私密和已删除目标没有入口。重复举报按已有待处理事实收敛，不主动触发限流。

## 6. 系统与弱网检查

- 加油、发帖、举报提交在途时按 Android 系统返回，弹窗/编辑器不得关闭，也不得产生第二个请求；结果明确后恢复返回能力。
- 上传或分页过程中断网再恢复：已输入 Markdown 保留，已加载内容不被空态替换，用户显式重试后只继续正确动作。
- 切到后台再返回、旋转锁定保持竖屏、改变系统字号后复查固定底栏、输入法避让和 320/360/400dp 等价布局。
- 收集失败页面的问题编号与操作步骤，不记录 Token、完整私信、预签名 URL 或测试账号凭据。

完成后应记录设备/Android 版本、APK 版本、五类角色结果、唯一 2 升账务记录、指定举报目标和所有失败问题编号；可逆测试内容与关系应恢复到测试前状态。
