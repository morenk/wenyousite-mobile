# 订阅玩家头像验收

状态：负责人验收通过／修复完成。原始反馈与验收日期：2026-09-13。

## 原始场景与预期

- 操作：进入一个可管理玩家发言订阅的主题，打开“玩家发言”列表。
- 实际：列表里的玩家都显示 ID／用户名的首个字符，没有显示已有头像。
- 预期：有头像的玩家显示头像；只有缺图或图片真实加载失败时才显示用户名首个可读字符。
- 原始输入限制：本任务没有取得负责人当时使用的主题、玩家、头像 URL、应用包名或设备信息，因此不会把构造账号数据冒充原场景复现。

## 已证实原因与修复范围

`ApiThreadSubscriptionRepository` 已从成员响应的 `avatar` 与 `avatarDisplay` 映射出 `ThreadSubscriptionCandidate.avatarUrl`，但 `_PlayerSubscriptionSheet` 创建共享 `WenyouAvatar` 时只传入 `username` 和尺寸，遗漏 `avatarUrl`。因此即使候选有有效展示地址，组件也只能执行缺图降级。

候选只补齐该参数传递，并加强展示地址映射与真实订阅面板组件测试；订阅筛选、读写、会话隔离、默认头像规则和其他头像入口均不改变。
