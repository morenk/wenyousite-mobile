# 移动端删除与状态反馈 UX 审查

状态：楼层原位删除与全部五项审查发现已于 2026-09-09 通过负责人真机验收，对应源码 `15d4b6b`、安装包 `6b194c06`。范围为删除、目标定位、404、自动分页及成功／失败反馈，没有对全部页面完成真机遍历。

## 已验收：原位删除与五项反馈简化

负责人在 `f4f05301` 包继续反馈删除后回到顶部，原问题验收失败／继续排查。原因是成功删除后调用完整 `refresh()`，网络读取之间把已加载楼层清空，滚动范围缩为零，再从第一页开始。带 120ms 网络间隔的 40 层真实页面回归复现：删除第 25、40 层时，旧实现滚动位置均变为 `0.0`。

当前候选 `removeDeletedFloor` 在服务端确认后只移除该楼层，复用 `refreshMetadata` 更新统计和权限；保留已加载窗口、分页坐标、排序和筛选。旧分页请求被代次取消，迟到结果不能补回已删楼层。沿用稳定行 Key 和滚动控制器，让相邻楼层填补空位；末尾自然收敛到剩余列表范围，不建立新的长驻定位目标。

页面覆盖中间、末尾、带目标坐标删除和长列表删除失败；控制器覆盖统计读取成功／失败以及分页迟到。删除失败不改变正文或位置，统计临时失败也保留已确认删除后的窗口。显式下拉刷新和筛选切换仍按原语义重新读取列表。

五项审查发现已处理：

- 动态评论：复用简洁确认，成功删除当前目标时结束评论定位；上下文加载／失败时不注入历史内容，外部不可见使用普通说明。真实页面验证取消、成功删除及旧链接；网络失败仍可单独重试。
- 普通楼层自动分页：页尾改为进度，取消正常状态的手动按钮；分页失败保留底部重试和已读正文。
- 主题不可见：404 不提供重复加载入口，保留页面返回；503 等临时失败仍可重试。
- 动态收藏移动：错误仅由选择弹窗展示；移除页面重复监听。取消收藏失败仍保留一次反馈，不被一并吞掉。
- 正文草稿：保存／删除成功改为短 Snackbar，取消常驻成功横幅；保留自动保存状态、失败和版本冲突处理。页面测试检查成功反馈会消失。

第一组旧实现对照共 30 项，10 项失败、20 项对照通过；候选同组全部通过。另补长列表定位／失败和分页迟到边界，均通过。旧实现失败证据包括两项滚动归零、动态删除路由未收敛、不可见状态颜色、无效按钮、重复错误和常驻成功提示。完整检查、APK 及负责人“验证通过”的确认见[汇总复验记录](mobile-regression-validation.md)。

## 上一轮反馈与候选（历史记录）

负责人在汇总包 `39e32767` 上反馈：删除确认解释“标记删除”，删除成功后又出现红色“目标内容已不可见”和“重试定位”。这属于正常操作被表现为故障，前一轮候选的删除 UX 验收失败，继续处理原问题。

原因已由真实页面回归证实：编辑保存会添加 `post` 路由坐标；前一轮失效了目标缓存，却保留坐标并重新查询已经删除的目标。原回归只验证旧正文不再补回，没有约束删除后的目标路由和错误提示。

本轮候选复用共享确认弹窗，只保留“删除这个楼层？”与取消／删除操作。成功删除当前定位楼层时移除该定位坐标，保留当前子贴，再刷新正文；删除失败不改变路由或内容。来自旧链接或外部删除的 404 使用普通不可见说明，不显示问题编号或无效重试；临时网络错误继续保留错误提示和重试。

`thread_deleted_target_test.dart` 共 7 项真实页面回归：旧实现 4 项失败、3 项对照通过，候选全部通过。覆盖普通入口编辑保存后删除、直接定位删除、普通入口直接删除、外部删除后刷新、删除失败、取消确认及定位网络失败后重试。不对共享线上内容执行删除测试。完整质量门禁和 APK 记录见[汇总复验](mobile-regression-validation.md)。

## 后续实现约束

- 删除成功同时结束失效的选中对象、定位和详情状态；测试不只断言数据消失，也断言不再报错、不再提供重试。
- 不可见内容与暂时加载失败分开；只有动作能够恢复当前操作时才提供重试。
- 一个操作在当前操作界面展示一次反馈。成功短暂确认，失败在能处理问题的位置保留。
- 确认文案说明必要的用户后果，避免解释存储和组件结构；不取消有价值的不可逆、权限或隐私说明。
