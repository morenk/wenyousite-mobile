# 图片上传体验候选验收

状态：候选／待负责人真机验收。公共 HTTP API、Markdown 协议、服务端 `COMPLETED` 语义与图片校验质量保持不变；本轮不部署、不安装真机。

## 原反馈与实现

用户反馈选图后的等待体感很慢，尤其“安全处理图片中”。没有获得对应用户的原图、网络和设备，因此不能断言已复现其端到端耗时。代码确认的等待来源为正文处理期间锁编辑，以及动态两个完整任务占住后续图片的传输名额。

- 正文确认裁剪、动态/评论确认选图后立即显示本机预览并后台上传；未确认选择或裁剪时不上传。允许继续写、增加图片；动态允许排序和选封面。
- 图片只显示 300ms 延迟动效及真实传输百分比；传输完成后等待处理不显示百分比，无整块“安全处理”横幅。失败逐图“重试/移除”，超时“继续/移除”。
- 点击发布只产生一个冻结意图；图片就绪才进入既有提交。等待期间取消继续编辑，失败/超时/离页/切号取消意图。请求发出后沿用原结果确认，不声称撤回。
- 准备 1 路、传输/确认 2 路、状态查询 2 路分别限流，服务端等待和退避不占传输名额。
- 本机草稿保留完整 Markdown、稳定附件身份、私有文件、处理 mediaId 与展示映射；没有 Delta 持久化。正文占位不进入正式提交、云端草稿或剪贴板。账号与目标隔离，离页暂停、重开续查/续传，但不恢复发布意图。
- 正文编辑基线变化时明确选择旧本机草稿或最新版；缺本机文件保留可移除占位。保存失败阻止无声离页，发布成功后的本机清理错误不转化成再次发布。

## 自动检查

核心回归包括原位更新不抢光标/不改顺序、删除迟到回调、undo/redo、剪贴板与提交防泄漏、暂停云端自动保存、确认响应丢失、服务端完成但源文件丢失、终态失败后重新传输、取消等待、不恢复发布意图、clear 后不复活草稿。

真实页面回归覆盖主题纯图片发布、连续编辑、等待一次提交、取消、失败重试、离页重开只续查；回复覆盖继续写、等待发布与取消；动态/评论覆盖排序封面、单图与表情互斥、更换图片失败保留原图及目标隔离。完整候选门禁 `npm run check:apk -- -TestConcurrency 4` 已通过：Flutter 4672 项通过，1 项显式线上 Sentry 接收验收按默认配置跳过；Windows 工具 18 项通过；格式、应用与生成客户端分析、架构、21 个模块文档、158/158 适用 API 覆盖、固定契约及生成一致性、公网 API/Markdown 兼容性均通过，同一门禁构建 Debug APK 成功。

## 负责人真机清单

在同一设备和网络分别使用照片、文字截图、透明图、GIF、九图组合；记录选图确认到恢复输入、全部图片就绪、点击发布到成功三个时长。对照前后候选使用相同样本，禁止以模拟调度数据替代实际提速。

1. 写主题、楼层、回复：裁剪确认后立即有图，继续输入、插第二张、移动光标；完成乱序时图位置、光标和文字不变。
2. 动态：前两图仍处理中时后图继续传输；调整排序/封面、移除任意待完成图。发布冻结内容，取消等待恢复编辑。
3. 评论：单图与表情互斥；已有图片替换时取消选择或失败保留原图；更换回复目标、关闭重开不会串图或自动发布。
4. 人为断网后重试、处理超时后继续；失败期间不得提前跳页。连续点击只创建一次。
5. 带待完成图片离页重进、重启应用、切换账号；正文和顺序保留，服务端已完成的媒体续查，缺文件显示可移除占位。原账号的发布意图不恢复。
6. 开启正文槽位自动保存后选图、继续写，云端不出现本机占位或路径；图片完成后同步最终正文。复制待完成图片只得到可见占位文字。
7. 小屏、大字号、亮暗主题检查图片角落操作可点；短于 300ms 的准备不闪动加载环。最终图片质量、透明、GIF 动画和阅读大图保持。

## 已知限制

- 取消评论回复目标后，为保护新草稿仍引用的附件，旧目标目录可能保留私有图片文件；本轮未实现跨草稿文件垃圾回收。
- 不增加系统后台上传；退出创作页或应用暂停后停客户端工作，服务端已接收的处理可以继续，返回后续查。
- 负责人尚未提供原反馈的图片、设备和网络，最终体验改善与图片质量仍待上述真机清单验收。
