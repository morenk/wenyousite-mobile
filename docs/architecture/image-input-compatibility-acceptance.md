## 目标、范围与实现

- 统一静态图片头识别、引擎尺寸读取、预览与裁剪路径，解除纯 Dart JPEG 解码对上传的单点阻断。
- 使用无损 PNG 中间态，原生编码器只处理已校正方向的标准图；最终按用途输出 WebP 85/92，输出完整解码通过才上传。
- 裁剪准备与上传准备共用一个工作协调器；动画 GIF 保留原始字节与预算检查，动态 WebP/APNG 明确拒绝。
- 格式、像素、大小限制保持；不变更后端协议、媒体用途、上传/确认/轮询、权限与发布策略。
- 不保证 HEIC、AVIF、BMP、HDR 保真、所有 ICC/P3 色彩与设备特有格式。本轮不引入原图上传回退，也不修改后端或 Foundation。
