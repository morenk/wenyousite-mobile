# 标签空格与回车录入候选

状态：候选／待负责人验收。只修改 Mobile 标签交互，不改变 API、生成客户端、Foundation 依赖或全局样式。

## 原问题与期望

从主题管理进入标签编辑器，输入“新标签 ”。原实现保留文本，需要按右侧加号；候选确认一个标签并保持输入焦点。普通 Enter、小键盘 Enter、软键盘完成同样确认，不把中文输入法选词当成添加。输入框保留“标签由空格或回车分隔”，删除加号和框外教学说明。

局部控件 `thread_tag_selector_sheet.dart` 保留5个、20字符、名称白名单与重复校验。连续粘贴可消费已确认项，但失败项和未确认尾部留在输入框；达到限制不会静默丢弃。完成先确认尾部再聚合保存，取消放弃面板暂存项。新建主题只统一提示，原空格／逗号解析不变。
