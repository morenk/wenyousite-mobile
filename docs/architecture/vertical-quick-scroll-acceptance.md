# 右侧纵向快翻验收

状态：候选实现／待负责人验收。旧横向快翻及两次定位修订的已验收记录保留于[阅读快翻验收](reading-quick-scroll-acceptance.md)，不代表本次纵向交互已通过真机验收。

## 需求与范围

- 主动点击顶栏原图标开启右侧快翻；主题入口位于最新回复右侧，独立讨论位于返回原楼层右侧。
- 局部悬浮且正文宽高和阅读位置不变；只有滑块接管拖动，轨道不接管点击。滑块局部底衬、主题色和尺寸来自正式 Foundation v6.11.0。
- 点滑块开启首尾、收起、加载状态和重试操作卡；卡片外点击继续执行正文操作，普通正文滚动关闭卡片。
- 作用域保持当前子贴／筛选／排序或原楼层及回复，沿用末端跟随和首次懒布局校正，不增加后端接口、预布局或图片预取。

## 负责人真机清单

1. 首次进入尚未读过的长子贴，点快翻，在滑块中部或边缘抓住上下拖动；中途不能提前到底，能停在十屏长单层内部。
2. 按住最下端等待新页和图片完成，正文继续向下；反向拖动、松手及中途取消后停止跟随。切换子贴／排序／作者与打开编辑器后收起。
3. 点滑块展开操作卡，测试首尾和失败重试；点卡片外的头像、链接、图片、楼层菜单及回复按钮，首次点击即响应，长按选字正常。
4. 独立讨论滑块、提示和操作卡不盖住发表入口；主题底部互动位置不变；系统侧边返回可用。
5. 320／360／400／600dp、大字号、明暗主题、键盘和 TalkBack 检查可调滑块与卡片所有操作。连续拖动观察帧稳定性；未采集前不声明已通过真机性能或 TalkBack 验收。
