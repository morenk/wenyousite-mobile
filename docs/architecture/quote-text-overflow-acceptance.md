## 已证实原因与候选范围

`flutter_markdown_plus 1.0.12` 在构造段落时固定 `forceStrutHeight: true`，覆盖 WidgetSpan 的实际行高。长行内代码虽然在内部换行，外部段落仍按单行分配空间，后续背景因此覆盖文字。

通过 MarkdownBody 公开的 build 扩展点，仅为包含占位组件的段落允许内容扩展行高；遍历该版本在受支持正文、标题、引用和列表中生成的块容器，保留文字、样式、事件和布局参数。普通纯文字行高与 Markdown 解析保持原行为，不编辑依赖缓存。以后升级渲染库须复核容器结构和相关回归。

WidgetSpan 已按父段落字号缩放其内容，因此内部关闭重复的 MediaQuery 文字缩放；系统大字号仍由父段落统一生效。修复涉及共享阅读组件，提及、传送门、骰子与表情同时检查实际高度和原交互。引用颜色、字体、内边距和圆角仍来自 Foundation v6.9.0。
