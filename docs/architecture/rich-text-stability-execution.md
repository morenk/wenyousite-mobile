## 3. 移动端保存与退出路径审查

`ThreadComposePage` 的发布、云端草稿保存/打开以及 `PostComposerSheet` 的提交/关闭均在继续前检查 `RichEditorSession.flush()`。主题离页路径中，原 `_flushSnapshot()` 返回 `Future<void>`；编码失败时直接返回，但 `_saveBeforePop()` 只检查本地存储失败状态，因此可能继续退出。

故障注入使用真实 `ThreadComposePage`、Quill 文档和 Codec：先保存有效正文 A，再模拟绕过字面来源保护的异常 producer 写入 `**待保存 B**`，独立确认编码确实抛出 `MarkdownCodecException`，随后触发系统返回。预期为保留页面、当前 Delta 和有效快照；连续返回不能丢稿；补齐正确来源属性后可保存并退出。

这是一条内部异常路径的可重复试验。尚未取得能由正常用户输入触发相同状态的原始复现，不能据此宣称已复现或修复用户过去遇到的丢稿问题。

## 4. 其他候选与独立反例

字面代码：共享 `rtb-literal-markers-whitespace` 原先把代码跨度里的 `<br />` 判作整行 HTML，导致打开后代码样式、可见文字不符。候选跳过完整代码跨度，关闭反引号必须整段长度相同；未闭合、错长及代码外 HTML 继续拒绝。旧共享用例红灯，候选及 9 个边界回归通过。

NBSP 阅读：同一用例的编辑/序列化已经通过，但阅读丢失段尾 NBSP。根因是 markdown `7.3.1` 的 `ParagraphSyntax.trimRight()`；适配器复用原段落解析，只恢复原文确有 NBSP 的被裁尾部，不抢占标题、列表或显式空段。共享阅读旧实现失败，候选及既有阅读组件测试通过。

撤销选区：原 Quill 按 Delta 长度估算位置，骰子替换撤销后原 `[0,1]` 选区变折叠，引用段首退格撤销后偏移多 1。共享预期独立来自操作前选区。候选把前后选区附着于原生历史条目，保留合并输入与选区方向；历史淘汰同步清理映射，替换文档清空映射，未经 Controller 的外部历史继续原生策略，不猜测选区。原共享回归失败，候选通过。骰子复制默认仍生成 UUID v4，仅增加测试用 ID 工厂观察实际复制后的身份。

原文保护：未知协议、原始 HTML、损坏节点或缺失对齐能力时，`RichEditorSession` 保留原 Markdown、只读展示并拒绝 flush；外部 `readOnly=false` 不能解锁。未改动的保护文档允许关闭，主题快照保留原文；改动过的异常文档不能走这一离页例外。原表格测试的“静默转义后保存”已被保护规则取代，另保留“未标脏仍检查当前有效文档”的独立回归。普通用户键入符号继续经字面输入路径保存。

实际 `PostComposerSheet` 覆盖编码错误、网络错误、`40002` 冲突与后端拒绝。失败保留当前编辑；编码失败无请求；冲突回读后明确覆盖才使用新版 version；恢复后提交当前正文。保存回执观察实际请求与假仓储持久化结果，不宣称公网 API 验收。

独立审查还发现图片方法缺只读防线、分隔线命令在历史记录结束后才更新最终光标、工具栏按长度误把等长表情替换当作没有编辑。回归已分别取到旧实现红灯；候选在图片入口拒绝只读，分隔线命令包含最终选区，异步工具只在文档签名未改变时恢复旧选区。没有跨 await 保持历史事务，也没有机械重写所有节点命令。

在已提交且干净的 Windows Worktree 执行 `pwsh -NoProfile -File tool/Export-RichTextBehaviorReport.ps1`。脚本运行四份共享测试并验证分片 SHA 和检查点唯一性，生成 `.dart_tool/rich-text-behavior/flutter-results.json`。编辑投影直接观察 Delta 和 UTF-16 选区；阅读投影读取已挂载组件的数据、语法及对齐配置，独立于 Codec；保存观测经过真实控制器/页面的仓储边界。没有以 fixture 预期填充实测值的回退。

报告绑定源码 SHA、fixture SHA、`platform=flutter`、`environment=unit-editor`；只使用固定脱敏语料，不收集真实正文、Token 或账号。交给 VPS Backend 候选运行 `pnpm contract:rich-text --compare <报告路径>`，校验 schema、完整性及首个差异字段。`canonical=null` 无当前阅读输入时显式 N/A，不能用旧快照或编辑 Delta 冒充阅读结果；其他未执行项目不能标通过。
