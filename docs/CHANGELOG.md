# 移动端变更记录

## 0.6.0+90 — 2026-08-28

- 同步后端契约 `5.14.0-dev.20260829.1`（revision `b653263f383f570879a169132fbe478fc41ecb13`）：正文升级为 Markdown v4、编辑器往返 v6、clipboard v2；OpenAPI 生成客户端零漂移。升级 Foundation 至 `v6.7.0`，消费同源对齐图标与移动编辑器能力契约。

- 移动端阅读、编辑与剪贴板完整接入普通段落和 H2/H3 左/中/右对齐：Codec 无损读写隐藏 marker，阅读态按块渲染且不显示协议文本，工具栏通过“更多”单入口循环对齐，列表、引用、普通图片、分隔线与空段继续拒绝。站内 clipboard v2 保留合法顶层块对齐，v1 仍可读取但不恢复对齐，外部 HTML/CSS 不推断格式。客户端冷启动与回前台同时接受 Markdown v3/v4，只有 `/meta` 明确声明 v4 时才开放写入入口，为后端后续独立激活保留兼容窗口。

- 主题详情顶栏在搜索与更多操作之间新增“跳到最新发言”指南针按钮，直接读取主题全部存活子贴内的最新有效坐标：主楼层复用现有目标定位、筛选恢复与重复居中链路，楼中楼直达父楼层独立讨论并聚焦具体回复；空主题禁用入口，请求期间阻止重复点击，删除竞态显示明确提示。

- 修复楼层、回复和子贴正文经自带长按菜单复制到本站编辑器后产生多余空行的问题：同一松散列表项目之间仅供 CommonMark 解析的空白，以及同一引用内分隔段落的空 `>` 行，不再进入 Quill 成为可编辑空段；不同内容块的间距与明确的 `<br />` 空段继续保留，系统剪贴板可见文本与进程内结构载荷使用同一规范结果。

- 修复 Android 后台尽力提醒可能永久吞掉消息的问题：应用在进程仍获系统调度时改为全程每 30 秒检查，不再在 10 分钟后降频；通知、私聊详情或系统卡片失败时不推进检测基线，下一节拍继续重试。消息频道在初始化时显式创建并校验全局权限与频道状态，关闭时不读取私有消息并在回到前台后明确提示；仍不接入 FCM、前台服务、后台唤醒或电池优化豁免。

- 同步后端契约 `5.14.0-dev.20260829.1`（revision `c7ade12aa3348e9a79661184478812806a23f6e6`）并重新生成客户端：新增 `postsFindLatestInThread` 及其主题最新有效楼层/回复坐标类型；当前只完成稳定契约接收，移动端消费入口留给独立业务切片。公网 `/meta` 已部署同一 revision，Markdown v3、编辑器往返 v5 与 clipboard v1 不变。
- 升级 Foundation 至 `v6.6.2`：公开主题标签改为仅保留 `#` 与 `brandStrong` 粉色文字的纯文字入口，移除常驻底色、描边和胶囊轮廓；48dp 命中区、悬停下划线、焦点环和管理态可移除编辑控件继续保留。

- 修复 Markdown 阅读态的嵌套行内代码样式：引用中的斜体行内代码现在合并外层 `FontStyle.italic`，同时保留等宽字体与紧凑字号；Foundation 固定依赖同步至 `v6.6.1`，阅读态与编辑态正文分隔线统一为 50% 内容宽度的居中短线圆点，可点击主题标签统一消费 accent/onAccent、primary 描边和 600 字重。

- 补齐 clipboard v1 的 Web → Android 富片段互操作：从本站阅读态或编辑器复制后，移动端编辑器会在严格重建 envelope 白名单后继承 H2/H3、强调、链接、引用、列表和分隔线；普通外部 HTML 仍按可见文本处理。阅读态图片/表情降为标签，Web 编辑器来源的合法站内媒体保留节点，骰子统一丢弃结果并生成新 `nodeId`，传送门与提及继续按安全目标恢复。
- 修复移动端阅读菜单绕过 clipboard v1 结构载荷的问题：子贴正文、主题楼层及独立讨论楼层/回复的“复制内容”现在从原始 Markdown 解码进程内 Delta，并以随机 marker、当前 `SessionScope` 和十分钟时效供本站编辑器恢复标题、强调、删除线、代码、引用、列表、分隔线、传送门、提及和骰子；Android 系统剪贴板仍只写干净的 `text/plain` 可见文本，阅读态图片与表情只留下 `[图片]` / `[表情]`。复制失败会清除载荷，显式重试重新捕获并写入新 marker；原生文字选区、跨设备只传文本、进程重启或 marker/会话/时效失配继续按普通文本粘贴。
- 修复 Web 发布正文中“引用内强调嵌套行内代码”经移动端楼层菜单复制后退化为 Markdown 源码的问题：阅读复制模式会把外层强调和内层代码拆成编辑器可安全保存的相邻样式，并保留空引用行；Web/CommonMark 的等价标题、引用、列表和分隔线写法会恢复为 canonical 编辑器块。样式内的传送门、提及和骰子继续恢复原子语义，图片/表情只恢复带周围文字样式的安全标签。系统粘贴动作可验证 marker/HTML 并恢复结构，输入法剪贴板历史若直接提交文字则固定按纯文本处理；常规 Markdown 编辑解码仍坚持严格无损往返。

- 收紧移动端发布与平台兼容基线：Android 明确关闭全量备份和设备迁移，本地发布在 ZIP 16KB 对齐后逐个校验 APK 内 ELF `LOAD` 段对齐；iOS 补齐应用名、相册用途、iPhone 竖屏与中文本地化声明，并以静态测试锁定共享代码边界。

- 错误底层改为稳定 `FailureReason` 与恢复动作，界面再按对象映射 `UserFacingFailure`，不再依赖后端文案；写入超时统一提示刷新核对且明确不会自动重复提交。反馈、空态、加载更多和异步图标按钮收敛为共享组件，新增亮/黑夜、横屏、2倍字号 Golden 以及命中区、语义和对比度回归。

- 优化系统选图内存与中断恢复：动态、评论、私聊和富正文选择以文件句柄预览，只在上传准备时读取字节；Android 进程在 Photo Picker 期间被终止后，下次启动可按原用途由用户确认恢复，不会自动上传。Drift 新增 v1 真实 schema 快照迁移测试，缺少未来升级路径时明确失败而不静默重建。

- 应用路由按主壳、认证、内容和账号拆分组合，公开路径与守卫语义不变；新增生产 provider 绑定冒烟和架构非增长门禁。在不跨越主版本的前提下升级 go_router、image、Photo Picker、SharedPreferences、SQLite 和 URL Launcher 等补丁依赖。

- 同步后端契约 `5.13.2-dev.20260828.1`（revision `51be1b9894949d4914e2df1bf8d40828bc595b58`）：编辑器往返黄金契约升级为 v5，恢复紧邻标点/符号的强调语义并以字符引用安全写回；新增 clipboard v1，系统剪贴板只写可见文本，进程内 Delta 继续由随机 marker、登录会话和十分钟时效共同保护。OpenAPI 与 Markdown 主版本不变，生成客户端零漂移。

- 他人资料页把拉黑/取消拉黑移到右上角，与举报作为同级图标操作，资料卡操作区只保留关注、加油、私聊和动态；动态详情的楼中楼展开入口复用主题帖组件，统一为弱化前景、普通字重、方向图标和不小于 48dp 的命中区。

- 同步后端契约 `5.13.1-dev.20260827.1`（revision `afd19ea640cf9d2288f6bfefe28bc6a2f88559eb`）并重新生成客户端：动态发现流与关注流统一按最后一条未删除评论时间顶帖，无评论时按动态发布时间排序；升级前游标沿既有 `40007` 逻辑从首页恢复，不再保留发现快照专属 503 路径。

- 主题管理工作台移除主正文与子贴正文编辑：主题设置只保留基本信息、发布设置、标签、私密邀请和删除，子贴管理只维护标题、发帖权限、排序与删除；默认及非默认子贴正文统一从主题详情的正文长按或右上角操作进入，元数据保存始终原样保留当前正文，避免软键盘收起后无法滚动到后续管理操作。

- 修复主题卡片只显示默认子贴旧活动时间的问题：首页、标签、搜索、用户内容和收藏列表现在都会显示主题全部子贴中的最新活动，其他子贴的新楼层与楼中楼回复不再被遗漏。

- 主题管理分区选择复用列表页筛选器的触发器、弹出菜单和选中标记；设置、私密邀请、子贴目录、成员空态与错误态改为留白加细分隔线的连续布局，不再用卡片包裹普通内容，胶囊仅保留给可操作控件。

- 首页分类、动态“发现 / 关注”和消息“通知 / 私聊”支持在内容区左右滑动切换相邻栏目，并使用 Foundation standard 180ms 方向位移反馈；分类页签保持稳定，首页只在内容区展示加载骨架，动态与消息保留已访问栏目，避免切换时整页闪烁或重复读取。短滑与首尾越界保持当前选择，减少动态效果时瞬时切换；消息继续同步规范 URL，底部主导航不参与横滑。

- 主题详情的子贴胶囊导航改为与左右 48dp 浮标共同占满内容行，中央标题使用剩余宽度；目录抽屉继续用细分隔线区分条目，但当前子贴改用贯穿整行的无圆角柔粉色带与勾选标记，不再套用胶囊高亮。举报原因复用列表筛选器的圆角菜单、选中标记和 48dp 选项，不再显示 Material 默认粗糙下拉。

- 主题帖普通正文图片改为保持内容宽度、左对齐并独占一行，不再与前后文字混排；收藏表情仍作为行内原子。普通楼层正文同时移除长度折叠、渐变和“展开全文 / 收起”操作，任意长度都直接完整显示。

- 精简移动端高频导航与创作：本人内容改为“概览 / 动态 / 创建 / 参与”四个同级页签，创作概览的四项统计在各自两列内居中；通知分类、私聊会话/请求/归档改为紧凑筛选菜单；收藏合并为直接展示默认夹的统一页面，并在移动、取消或新建后同步目录计数，刷新失败保留当前列表。

- 重排主题管理的“主题设置”：基本信息、发布设置和主题标签使用明确分组，招募状态与可见范围改为直接点选并立即自动保存，移除窄屏并排下拉和空标签区的弱层级。

- 正文草稿面板固定展示五个草稿位，每个位置都可明确“保存到这里”，同时保留自动选择空闲位；自动保存仍只写入草稿位 1。服务端版本继续用于并发控制，但不作为用户界面信息展示。

- 统一找回密码、验证码和凭据输入：重置页默认显示脱敏邮箱摘要，可修改目标并紧凑重发；新邮箱发码明确失败时保留编辑态且不沿用旧地址的成功提示。账号设置不再等待本人资料读取，资料编辑加载与失败状态改用结构 Skeleton 和明确重试。

- 统一上传状态、原图查看、分页尾部、页面错误与确认对话框等共享实现；动态无图创作只保留单一添加图片入口，文字封面采用 Foundation 展示字体且不重复标题，评论长按优先系统选字，公开用户与动态的加油/举报移入有标签操作区。

- 加油弹窗提供 2、5、10 升预设和按需出现的自定义金额，预设暴露选中语义，确认按钮显示当前金额；金额单位统一为“升”。

## 0.5.0+89 — 2026-08-26

- 修复传送门在阅读正文中与前后文字水平位置错乱的问题：Markdown 与纯文本场景统一按 alphabetic baseline 参与同一段落排版。各内容复制入口向系统剪贴板写阅读态可见文本，传送门、提及、骰子和规范表情等行内原子只显示 label；支持结构恢复的主题正文、楼层和回复另把 Delta 留在当前进程，系统选字复制同样不泄露目标地址或协议节点。

- 收紧主题楼层与独立讨论的控制行：作者筛选与排序统一为 12sp 安静排版，作者触发器按内容收缩且最宽 112dp，菜单保留独立宽度；楼层、回复与动态评论的可见排序文案统一为“正序 / 倒序”，读屏仍说明“最早在前 / 最新在前”。多子贴冻结导航居中收至最宽 296dp，中央可见胶囊高 36dp，普通态整栏 56dp、冻结态 48dp，放大字号时按双行文字实际高度扩展。

- 个人资料页移除“预览公开主页”，本人资料卡底部统一为编辑、收藏和按能力显示的表情包图标操作；他人资料卡将关注、拉黑、私聊和动态收敛为无背景、无边框的等宽图标短标签，创作概览同步压缩为单层外卡内的 2×2 统计。
