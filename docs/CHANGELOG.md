## Unreleased

### Added

- `/compose/thread` 接入真实主题创作页：Flutter Quill 工具栏、服务端分类/邮箱状态、按账号隔离的本地防丢快照、持久化创建幂等恢复，以及 `threadsCreate` 草稿后再用 `threadsSaveAggregate` 保存或发布的两阶段链路。
- 编辑器图片接入相册选择、10MB/类型校验、独立无鉴权预签名 PUT、确认与完成态轮询；只有 `COMPLETED` 的安全 HTTP(S) 原图会插入 Markdown，并提供上传取消、状态提示及可缩放全屏查看。
- Markdown ↔ Delta 编码器支持粗体、斜体、删除线、行内代码、安全链接、二三级标题、引用、列表和分隔线；不支持或冲突的格式会阻止保存，避免静默丢失。
- 建立自研 Markdown v2 扩展节点 ↔ Quill Delta Codec：提及、全体玩家、骰子、表情、图片与独占空段使用稳定内存协议；未知版本、非法节点和危险图片以只读兼容 embed 保留原文。
- “我的”新增修改密码与更换邮箱：严格映射三个后端账号安全端点，换绑验证码支持 60 秒/`Retry-After` 冷却；任一操作成功后按服务端全会话撤销语义清除本机 Token 并要求重新登录。
- “我的”新增登录终端管理：读取当前活跃 Web/移动端会话，当前终端只读，其他终端二次确认后按稳定 ID 撤销；界面不读取或展示已废弃的原始设备标识。
- 底部通知分支接入真实站内通知：支持六组类型筛选、游标分页、结构化 payload 文案、游客登录引导、下拉刷新、目标失效提示及主题/楼层/用户精确导航。
- 接入通知单条已读、全部已读、删除与独立未读数闭环；底栏角标每 30 秒和回前台刷新，写操作同步角标，乐观已读失败回滚并重新校准服务端未读事实。
- “我的”新增本人收藏管理页：接入游标分页、主题摘要导航与按收藏记录 ID 原地取消；删除分页尾项时回退到仍有效游标，失败保留条目和请求 ID。
- 主题详情接入官方更新与玩家发言两类订阅：普通登录用户可按服务端记录 ID 可逆管理，玩家面板只展示已标记普通玩家，楼主/协作者沿用自动通知并隐藏控件。
- 主题详情接入点赞/取消点赞与收藏/取消收藏：游客点赞先登录并保留帖子目标，登录用户使用服务端权威计数和收藏记录 ID，失败保留原状态与请求 ID。
- 新增关注、粉丝与黑名单移动端列表：公开用户统计进入指定用户列表，“我的”进入本人列表；黑名单支持失败保留、请求 ID 与原地取消拉黑。
- 公开用户主页新增关注/取消关注与拉黑/解除拉黑闭环：认证身份确认后显示，关系写入串行化，拉黑二次确认，失败保留原状态与请求 ID。
- “我的”分支接入本人真实资料与编辑闭环：展示邮箱验证、成长进度和统计，支持独立改名、简介与三项公开范围更新，并保留失败重试和安全退出。
