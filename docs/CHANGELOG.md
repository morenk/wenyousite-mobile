# 移动端变更记录

- 修复主题、楼层、回复和子贴正文中普通文字与原子表情包组合后可能无法安全保存的问题：异步选择器现在固定使用打开前选区，协议 embed 不再继承光标处待应用的粗体等属性；Markdown v3 严格校验、标准表情标记和私信独占表情语义保持不变。

- 修复主题订阅者收到楼中楼回复通知时被误写为回复对象的问题：实际回复目标本人继续看到“回复了你”，订阅者或管理者看到“回复了用户名”，缺少目标字段的历史通知中性显示“回复了”；通知筛选、已读状态与楼层精确跳转保持不变。

- 重构 Markdown 编辑器块语义：分隔线以单次 Delta 事务插入，固定写为两侧结构空行的独占块并支持单步撤销；历史 Setext H2 编辑后规范为 ATX H2，保存前重新解析校验块结构，编辑态与阅读态统一使用 Foundation `border` 1dp 实线。

- 同步后端契约 `5.11.3-dev.20260825.1`（revision `bfee39e371483b54aae54e68b72e784d64662d36`）；编辑器往返黄金契约升级至 v4，固定独占分隔线块边界与历史 Setext H2 规范化，HTTP API、OpenAPI `5.11.1` 与 Markdown v3 均不变。

- 新增全局亮色/黑夜外观：游客与登录用户都可从“我的”进入公开外观页，选择跟随系统、亮色或黑夜；偏好在 Flutter 首帧前从本地恢复，系统状态栏、导航栏、图片查看器、Markdown、编辑器与共享组件统一消费 Foundation v6.5.1 深色语义 Token，读写失败可见回退并重试，原生静态启动层继续保持白色。
- 统一动态评论排序交互：顶层评论继续默认最新，改用主题帖同款“最新在前 / 最早在前”直接切换并移除作者筛选；每条动态评论下的内嵌、分页和通知定位回复均消费后端正序结果。
- 强化连续讨论与消息状态的阅读层级：主题主楼层和独立讨论顶层回复改用更清晰的 Foundation `input` 1dp 分隔线，正文 Markdown 分割线保持更浅的 `border`，内嵌回复软面板不变；通知未读点、底栏消息合计与私聊会话计数统一改用 destructive/onDestructive，计数固定 16dp、10sp、`99+` 上限，其他普通 Badge 仍保持品牌色。

- 修复移动端编辑器会把关系外全站用户列为可提及对象、发布后后端不会生成通知的问题：候选与 Web 对齐为只使用当前主题授权的关注用户和已标记玩家，未知关系失败关闭；规范提及 Markdown、`@全体玩家` 权限和历史正文呈现保持不变。

- 同步 Web 端楼层连续空段落兼容：阅读和编辑历史正文时，把顶层多余原始空行逐个恢复为 Markdown v3 独占 `<br />`，首尾空段与 CRLF 统一处理，围栏代码、缩进代码和原始 HTML 块保持字面内容；阅读态相邻标记分别贡献真实行高并参与长文折叠，紧凑预览继续收束空白，Quill 保存后写入 canonical 标记且重开不增减段数。
- 修复移动端编辑器连续回车产生的空段在发布时被消灭：区分已有 Markdown 结构分隔与用户新建空段，不再信任 Quill 复制到新换行的末行属性；键盘、IME、外部粘贴、自动草稿、本地快照及主题/子贴/楼层/回复保存发布统一把首部、尾部和连续空段逐段写为 canonical `<br />`，已有普通段落边界保持原样。
- 修复动态评论通知只能进入详情、无法定位具体评论的问题：通知保留稳定评论坐标，详情通过 `momentsCommentContext` 直接补取主评论和目标回复并滚动，不扫描评论分页；主评论、楼中楼和墓碑上下文均只短暂框选目标，目标不可见时保留正文和普通评论，临时失败可单独重试定位。
- Foundation 固定依赖升级到 `v6.5.0`：同步最新正式视觉事实源；新增主题偏好、黑夜色板与主要行动角色保持为兼容能力，V1 继续只启用既有亮色主题。
- 修复动态双列瀑布流在滚动到底部或加载下一页后偶发错列、右侧长期空白且无法继续下滑的问题：卡片、加载更多和结束状态改由同一瀑布流统一计算，分页追加与反复滚动回收后仍保持连续双列和完整滚动范围。
- 修复私聊和动态回复输入框被图片、表情、字数与发送按钮挤窄、输入少量文字便提前换行的问题：正文改为独占首行并横向铺满，操作统一进入下方一行；动态评论移除关闭按钮，点击外部暗区或系统返回即可收起并保留当前草稿。
- 修复从站内传送门、消息通知、个人资料最近回复等带子贴或帖子坐标的入口进入主题后无法切换子贴的问题：入口坐标只执行一次初始定位，完成后前后按钮和目录选择不再被原入口反复覆盖；帖子归属仍在读取时以用户选择为先，迟到结果不再拉回原子贴，同主题详情重复压栈也不再共享选择与分页窗口。
- 修复编辑器外部粘贴可绕过 Markdown Codec、导致发布被服务端以 `40009 UNSUPPORTED_MARKDOWN_FORMAT` 拒绝的问题：系统富文本、受支持 Markdown、表格、HTML、任务列表、非法标题和硬换行等外部内容统一按可见普通文本写入，并在编码出口自动转义；Android 内部结构化复制必须同时匹配随机剪贴板 marker 与登录会话，粘贴竞态或序列化后超过 10000 字符整次拒绝。主题创作、子贴正文、楼层/回复、云草稿和本地快照保存前等待在途粘贴并从当前 Delta 重编码；历史安全转义重新打开不显示实现字符。移动端“分隔线”固定放在“更多”，不再因主栏与面板分别计算宽度而从两处同时消失。
- 修复荣耀 Magic8 等窄屏安全区机型进入主题帖子详情后正文与顶栏留白、互动按钮停在屏幕中部的问题：现场 A/B 日志确认请求、解析、正文布局、窗口指标及 Impeller/Skia 均正常，根因为仅图标发表分支的右对齐容器接受整屏高度，令底栏占满窗口并把正文滚动视口压成 0；该分支现按图标固有高度收缩。响应式回归扩展至 320～800dp 宽、480～1280dp 高、2～4 倍 DPR、三键/手势导航、折叠屏窄幅、短窗口、手机/平板和 1.0～2.0 倍字体，并分别验证游客与登录态底栏。现场诊断改为默认关闭的编译期能力，普通用户 Debug 与 Release 包不显示入口且不调度采集；需要异地排障时从同一提交显式生成专用诊断包，无需维护独立分支。启用后的全局“诊断”入口可一键复制脱敏的设备/版本、原始与有效窗口指标、帖子渲染事件、异常类型和堆栈，不包含正文、帖子 ID、账号、Token、私聊或请求 URL；面板控件不依赖导航器 `Overlay`。详情页在首帧、750ms 和 2500ms 采集路由、Scaffold、顶栏、滚动视口、题头、正文、Markdown 与底栏的真实屏幕坐标、约束、可见比例、变换矩阵和滚动范围，并支持默认 Impeller 与禁用 Impeller 诊断包顺序 A/B。
