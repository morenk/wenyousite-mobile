### Added

- 实现 0.3 公开阅读切片：首页主题卡片进入稳定主题详情，详情展示元数据、子贴 Markdown v2 正文、升序楼层分页与服务端内嵌回复。
- 新增安全 Markdown 阅读组件，支持外部链接/图片协议约束和服务端骰子结果展示，并为未知结果提供可复制的降级文本。
- 实现首页推荐主题流首个闭环：公网列表、服务端动态分类、状态/排序筛选、下拉刷新、游标分页及紧凑粉白主题卡片。
- 建立 Flutter Android 工程、固定 OpenAPI 生成链、契约快照、中文模块文档体系与文档门禁。
- 建立粉白主题、应用环境、网络/会话、本地持久化与 Markdown v2 基线。
- 确定 Flutter Quill 仅作内存编辑模型，并建立自研 Markdown v2 ↔ Delta Codec 边界与测试规范。
- 同步 Markdown v2 扩展节点往返语料和 mobile push v1 Schema/黄金样例，为后续编辑器与推送切片固定跨端边界。
- 实现账号/密码登录、mobile 终端声明、双 Token 安全落库，以及创建主题入口的登录回跳。
- 完成会话刷新与退出闭环：并发刷新锁、单次请求重放、失效原因导航、服务端会话撤销及明确确认的本机退出后备。
- 实现邮箱验证码两步注册、重发冷却、专用错误状态、mobile 双 Token 自动登录及原目标回跳。
- 建立粉白 Misskey 风格视觉设计系统、语义 Token 与面板、区块标题、状态提示、异步主按钮、空状态等共享组件。

### Changed

- 开发版本进入 `0.3.0-dev.2+8`，主题与楼层模块进入 `in_progress`；本轮保持只读，独立楼中楼页、精确定位、回复及其他写操作后置。
- 首页刷新入口收敛为下拉刷新和错误态重试，主题卡片承担进入公开详情的明确导航职责。
- 详情阅读正文规范调整为约 17sp、1.75–1.85 行高，内嵌回复使用 16sp、约 1.75 行高，并补充主题详情与两层回复的面板规范。
- 开发版本进入 `0.3.0-dev.1+7`，首页从应用壳占位页切换为真实公开内容流。
- 同步后端契约 `4.4.0-dev.20260809.1`：主题分类改为服务端动态配置，主题列表增加封面与温油数据，并接入动态、钱包、成长体系及分平台构建兼容类型。
- 启动兼容门禁切换到后端 `4.x` 主版本，并继续拒绝未审查的未来主版本。
- 第一阶段开发改为相关本地检查与真机冒烟优先；GitHub Actions 暂停自动触发，仅保留阶段验收时手动执行。
- 修复生成 API 客户端与 Dio 基地址重复拼接 `/api/v1`，导致真机启动请求 404 的问题。
- OpenAPI Dart 客户端使用稳定的 `built_value` 序列化，未知枚举安全降级。
- 刷新和退出统一通过生成客户端发送稳定请求 ID；重放再次过期或收到 `40103`～`40106` 时清除本地会话并进入登录页。
- `ApiFailure` 读取 `Retry-After` 并为验证码过期/错误、邮箱已注册和用户名占用提供稳定移动端提示。
- 应用壳、启动状态、登录和注册统一为粉白面板样板，使用深色前景主按钮、弱粉选中态、响应式页边距和至少 48dp 触控区域。
