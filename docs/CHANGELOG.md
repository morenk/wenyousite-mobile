# 移动端变更记录

本文件从当前已部署开发基线开始记录活跃变化。build 83 及以前的完整开发历史保存在 [历史变更记录](archive/changelog-through-build-83.md)。

## Unreleased

### Changed

- Foundation 固定依赖升级到 `v6.0.1`，接入 72 小时时间格式、五档等级色与等级进度，并采用新的内容、控件和骰子呈现契约作为后续页面事实源。
- 复核并同步后端契约 revision `e1b6bc3a288104488944ecfcd417a623daa82099`；契约版本仍为 `5.0.0-dev.20260816.1`，规范化 OpenAPI、Markdown v3 固定语料与生成客户端均无内容漂移。
- 重排移动端主题详情：题头只保留最多两行的主题标题与独占行子贴选择器，完整子贴信息留在目录；喜欢、收藏、订阅和发表楼层固定到底部拇指栏，玩家退出移入“更多主题操作”的身份面板。
- 子贴正文与楼层之间新增全宽细分界线，移除“楼层/最早在前/最新在前”常驻说明；排序图标改为单击直接互换正序与倒序。
- 写操作新增统一的结果校准与中性反馈：订阅、主题点赞/收藏、关注/拉黑、主题标签、成员、登录终端和子贴管理在超时、断线或指定可收敛冲突后读取最新投影，目标已达成即按完成处理；无法确认时只提示刷新查看并保留问题编号，不自动重复普通写请求。
- 主题标签改为“按名称关联”的统一操作：标签可被多个主题复用，同名标签自动复用，用户无需区分首次建立标签与后续关联。
- 调整“我的”资料与内容布局：收藏移至编辑资料旁，主页签与帖子二级页签居中；概览按 Web 端结构补齐创作概览，并继续展示最近回复。

### Fixed

- 修复 Quill 编辑器粘贴整段合法站内链接后未立即显示传送门；真实原始编辑器粘贴入口现在生成可稳定序列化的原子节点。
- 修复已发布传送门因透明命中容器横向撑满而居中独占一行；阅读态改为横向按内容收缩，编辑态按文字基线与前后正文混排。
- 修复普通 POST 在登录状态刷新后可能被自动重复提交；只有安全读取、语义幂等更新/删除和携带稳定 `clientRequestId` 的创建请求允许自动重放。
- 修复订阅创建已落库但响应超时、或返回 `40904` 时仍显示失败；现在只有重新读取到 `threadId + type + targetUserId` 精确记录才收敛为成功，`40912` 等内容冲突仍明确失败。
- 修复搜索页楼层内容结果会随正文长度收缩；动态、主题帖、楼层内容、用户及主题内楼层搜索结果现在统一占满单列可用宽度，并覆盖同类嵌套回复列表。

## 0.3.0-dev.79+85 — 2026-08-17

### Changed

- Foundation 实现改为每次以远端最新正式发布 Tag 为准，并将依赖从 `v3.1.0` 升级、锁定到最新 `v5.1.0`；同步迁移元素契约、语义图标及其破坏性 Token 变化。
- 动态纯文本与主题 Markdown 的站内坐标统一渲染为 Foundation 轻量传送门胶囊：使用门图标、柔粉表面、600 字重、可换行且不截断，并保留 48dp 命中区和内部导航语义。
- 主题与帖子编辑器识别整段粘贴的合法站内链接并插入不可导航的原子传送门；已有选区作为名称，无效坐标、混合文本和站外链接保持普通粘贴。
- 同步后端契约 `5.0.0-dev.20260816.1`（revision `2fd8c979ef10c0e1dec3a3ca23b59d3b8f99c0ca`）：移除主题分类颜色字段，主楼层支持“最早在前 / 最新在前”的稳定游标分页，Markdown v3 不支持结构在阅读端统一安全字面化。
- 主题与动态的点赞/收藏统一使用 Foundation v5.1 专用语义色、透明选中容器和 Foundation 提供的实心图标；提交中保留当前选中投影，只读消费者保持中性。
- 契约同步与完整检查脚本统一使用 PowerShell 7 `pwsh`。
- 头像上传新增可拖动、缩放的 1:1 取景窗口；主页背景改为从同一原图分别调整电脑端 3:1 与移动端 2:1 取景，确认后生成严格尺寸并上传，失败重试继续复用已裁剪结果。
- 主题楼层、楼中楼与动态评论的长按操作改为居中遮罩小窗口，点击暗区关闭；帖子和评论半屏输入点击暗区即收起并在当前页面恢复本地草稿，私聊输入点击外部区域收起键盘但保留文字，非主题输入不自动上传云端。
- 重构“我的”主页：资料背景采用 Web 端排头结构，72dp 头像一半嵌入 2:1 背景；主页签调整为“概览 / 动态 / 帖子”，帖子二级筛选“创建的 / 参与的”，并移除“我的内容”标题及说明。
- “我的”将“温油 / 收藏”收进关注、粉丝同级统计入口；收藏独立页统一承载主题帖收藏夹与动态收藏，创建/参与/收藏主题复用公共主题卡片，动态收藏复用公共动态列表。
- 首页主题分类改为 Web 风格横滑分类栏，主题排序与状态使用紧凑锚点下拉框；动态页及个人页内容筛选统一使用 Web 风格线性页签。
- 主题详情移除顶部重复标题，将帖子标题在工具栏下方居中显示；移动端用户可见文案统一改为用户视角，主题关闭状态显示“已停招”，失败状态不再暴露响应、协议或跨端实现说明，诊断字段改为“问题编号”。

### Fixed

- 补齐 Flutter Quill 中文本地化代理，修复长按已有链接时因链接菜单缺少本地化实例而报错。
- 修复互相关注用户发起私聊时仍误显示“这会先作为消息请求”；陌生人才展示请求提示，最终会话状态仍以服务端回包为准。
- 私聊复制、收藏表情、接受请求等黑色短提示改为浮在输入 dock 和软键盘上方，不再遮住输入框。
- 邮箱验证码发送禁止自动重放；超时、断线、429 或 5xx 导致结果不明时进入“邮件可能已发出”验证态并保留请求 ID，不在背景重复发码。
- 修复个人背景图未按资料卡圆角裁切、帖子头像被外层回复手势吞并，以及 Android 从后台恢复后陈旧键盘高度导致页面下半部分消失的问题。

## 0.3.0-dev.78+84 — 2026-08-16

### Changed

- 同步线上后端契约 `4.14.0-dev.20260815.1`（revision `9752c2289acb0db19af7d91d98978adb558991bf`）：移除 `emailVerified`、登录后邮箱验证接口和全部写操作邮箱验证门槛；注册验证码仍在创建用户前完成。
- 接入用户主页双画幅背景：同一图片自动生成电脑端 3:1 与移动端 2:1，双媒体上传后原子设置，移动端优先使用 2:1 并安全回退电脑端；支持取消、断点式重试和确认移除。
- 接入公开用户活动汇总，独立展示动态、自建主题、参与主题与公开回复计数；隐私关闭字段明确显示“未公开”，加载失败可单独重试且不阻塞资料和内容分区。
- 归档已失真的初始里程碑和累积式变更记录，重建以当前发布事实、未完成能力和可验证优先级为中心的文档基线。
- 模块状态由文档门禁统一校验，并修正通知定位、站内邀请、私聊兼容路由、动态评论定位端点、搜索分页债务和 Markdown 安全字面化等语义漂移。
- 统一移动端公开主页预览只读语义、私聊/评论/编辑器发送按钮状态、主题创作元信息与正文草稿入口，并将输入框编辑菜单固定为中文。
- 动态评论楼层改为点击非交互区域直接回复，举报/删除收进长按操作菜单；楼中楼回复与主题帖预览复用统一软面板楼层组件，个人资料主题卡不再展示原始分类 slug。
- 轻量操作统一为锚点气泡：私聊收藏表情保持键盘态展开，消息、楼层、回复与评论长按在内容旁操作；全局发布、云端草稿和主题更多不再打开底部抽屉，复杂表单与长列表 Sheet 保持原结构。
