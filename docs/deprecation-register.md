- 逐条模式增量：`identityMode: ACCOUNT|RP` 为可选字段，省略保持旧兼容；ACCOUNT 明确使用账号，RP 要求有效显示和本人 token。编辑旧正文忽略新模式，成功幂等重放仍返回原帖。本轮不删除缺省协议。

- 固定 Backend `5ab9767ff8ddce917ddb2560ea655bb58a2408a3`／`5.33.0-dev.20261005.1`。新增五个身份端点与可选展示字段；账号 ID、用户名、头像、订阅和筛选语义继续保留。
- 旧响应缺少身份字段时降级账号资料；旧客户端在有效 RP 下缺少确认 token 的创建会明确失败，不能静默换身份。关闭 RP 保留历史快照；回滚消费者不删除身份表、快照和历史头像引用。
- Markdown 正文继续保留原始提及标签和账号链接，仅阅读时应用服务端的 userId + label 映射。先兼容 Backend，再共享规范与消费端；本期不清理任何旧协议，不代表已合并或部署。
