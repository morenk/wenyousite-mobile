# 温油工具箱

状态：`in_progress`

功能与视觉候选／待负责人验收。

## 1. 模块目标与非目标

提供原生工具目录与受约束 WebView，复用温油 Web 的文字处理页面。首版包含文字竖排、摩斯编码、花体英文、起名工具。算法、词库和结果复制由网页维护；不复制 Dart 算法、不新增业务 API、登录同步、历史或收藏。

## 2. 用户角色与使用场景

游客与登录用户都可从“我的”打开工具箱。起名支持中国、日本、英国、德国、法国、俄国、美国、意大利、西班牙、韩国、巴西，中文另有古风和幻想角色名。

## 3. 页面、入口和导航关系

“我的”右上角“工具箱”始终可用，不依赖个人资料加载成功。原生目录为 `/tools`，详情为 `/tools/:toolId`，未知标识返回目录。详情加载固定 `https://wenyou.site/tools/embed/{vertical,morse,fancy,names}`。网页目录链接回到原生目录，原生返回直接退出工具，不逐层回放网页历史。

## 4. 用户操作流程

选择工具，等待网页打开，输入文本或选择起名条件，生成并复制结果。首次打开需要网络。默认右阅读顺序、列间空格数、摩斯字符支持及起名数据规则由已提交 Web 契约管理。

## 5. API operationId 与生成类型

工具模块不调用 Backend API、不使用生成类型。应用原有启动检查 `metaGetMeta` 属于 app-shell；它不是工具箱请求，工具页不注入 App 的 Dio、Token 或会话。

## 6. 状态模型和数据流

原生枚举记录四项工具身份、名称和描述。WebView 状态为加载中、可用、失败。嵌入网页链接按 Web 契约使用普通 `<a>` 完整文档导航；主文档事件更新原生标题，每次重试创建新的控制器并忽略旧代回调。主题以打开页面时的亮暗快照通过 `theme=light|dark` 传入；本次停留期间主题固定，避免主题改变重新加载导致丢失输入。

## 7. 鉴权、权限和隐私规则

只允许 HTTPS、`wenyou.site:443` 以及契约列出的嵌入路径，仅接受单个有效 theme 参数。阻止认证页、其他路径、第三方来源、任意查询参数、fragment、userinfo、文件或外部应用 scheme。没有原生 JS bridge、Cookie 注入、授权请求头或外部打开动作；不读写页面文本日志。固定 `window.stop()` 只用于终止超时或非允许导航，不读取内容。

Android 禁止文件/content URI、定位、混合内容与文件选择；所有 WebView 权限请求拒绝，HTTP 认证取消，SSL 错误取消。插件不会打开独立原生窗口；Android 新窗口请求经插件转给同一个导航白名单。子资源安全仍依赖自建网页的 CSP 与构建资源，不将主文档导航白名单宣称为网络防火墙。

## 8. 本地存储、缓存及失效规则

不建立工具历史或收藏，不共享安全存储和 App 登录态。输入和结果按 Web 契约仅在页面内存存在；退出、重试或重新加载会清空。系统 WebView 可缓存网页资源，不能据此承诺离线。主题不写网页存储。

## 9. 加载、空数据、错误、重试和冲突状态

使用共享骨架展示打开过程。主页面网络错误、HTTP 错误、初始化失败或超过 25 秒未完成时显示“工具加载失败”及重试；迟到的完成事件不能掩盖错误。词库及其他子资源失败由网页提供局部重试，不替换整个原生页面。没有输入的提示由具体工具页面负责。

锁定的 WKWebView 3.26.2 在 navigation response 的 HTTP 错误中不提供 request，故无 request 仍按文档失败处理；工具契约不含 iframe，容器也拒绝子 frame 导航。有 request 的资源错误只在地址为当前文档时触发整页失败，并由平台替身覆盖该差异；这不代表 iOS 真机验收。

## 10. 跨模块约束

users 只提供路由入口；app 组合工具页面。复用 Foundation v7.2.1 的 Token、系统字体与语义返回图标，不发布新 Foundation。业务 API 地址不作为工具来源。按负责人本轮决定，开发与候选均使用公网域名，不建立专用预览地址、转发或调试覆盖参数。

## 11. 测试场景与验收条件

自动测试覆盖访客入口、四工具路由、未知标识、URL 白名单与注入、亮暗快照、主页面/资源错误分离、重试旧回调、超时、返回和窄屏。WebView 平台替身验证真实页面连接到平台的请求，不访问业务网络。新增官方插件与网络承载面按高风险执行 `npm run check:apk`。

负责人在兼容 Web 已合并并部署后手测：从游客及登录的“我的”打开四工具；切换亮暗再进入、输入与键盘遮挡、长按及按钮复制、跨工具/目录导航、系统返回、断网重试、超时恢复、竖排 emoji 与间距、摩斯错误输入、花体保留中文、十一国及中文风格起名。

## 12. 已知限制和后续功能

尚无真机/WebView 画面与负责人验收。现有应用启动/登录恢复可能自动签到，代理不启动真实环境 App。仅交付 Debug APK 供负责人主动使用；没有连接设备时不安装、不卸载或清数据。Web 工具必须先合并部署，未部署时公网工具路径不可用属于已知发布依赖。不支持离线或 iOS 签名验收。
