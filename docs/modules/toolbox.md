# 温油工具箱

状态：`in_progress`

Flutter 原生四工具与双语起名候选／待负责人验收。

## 1. 模块目标与非目标

工具目录和四工具表单使用 Flutter 原生组件，转换及起名在设备本地计算。进入工具即显示输入，无 WebView、网页初始化或工具网络请求。首版包含文字竖排、摩斯编码、花体英文、十一国及中文古风／幻想起名；不新增 Backend API、账号要求、历史、收藏或文件权限。

## 2. 用户角色与使用场景

游客及登录用户都可使用。国家包含中国、日本、英国、德国、法国、俄国、美国、意大利、西班牙、韩国、巴西；所有外国结果同时提供原文和中文写法，采用小型常用双语词库，优先译名质量，不自动机器音译。中文姓名本身即中文，不重复显示。

## 3. 页面、入口和导航关系

“我的”个人功能带并列收藏夹、表情包、油卡与工具箱；游客及资料加载／失败时保留独立工具箱入口。原生目录 `/tools` 与详情 `/tools/:toolId` 保持，未知标识回目录。四工具都有单一原生标题和返回，系统返回离开页面，重新进入清空本次输入和结果。

## 4. 用户操作流程

选择工具，输入条件，点“生成”或“转换”，选择文字或复制结果。参数沿用设置页分组行，选择值点开抽屉，数字与固定姓氏行内编辑；正文使用独立输入区，生成动作位于参数组外。工具箱局部标题、字段、操作与结果均使用常规字重，花体输出字形不受此规则影响。

结果内容区按窗口可用高度限制到 45% 且最多 400dp，短结果按内容收缩。超高内容在框内上下滚动并持续显示滚动条；竖排横向超宽也持续显示滚动条，从所选阅读方向开始。复制操作留在结果滚动区外，每次重新生成回到开头，复制仍包含全部结果。

- 竖排默认页宽 10、页高 20、列间 2 个 ASCII 空格、从右向左。宽高范围 1–100，间距 0–10；可改为不含控制字符的最多 20 UTF-16 单元分隔符，空分隔符有效。结果按阅读方向显示起始侧，可横向滚动；复制严格保留空白，不重排或 trim。
- 摩斯支持国际拉丁字母、数字、既有标点与 É，按行转换；解码用空格分隔字符、`/` 分隔单词，未知字符／码组明确报错。
- 花体提供粗体、斜体、花体、哥特体、双线体、等宽体、全角；选择器显示实际字形样例，保留中文、Emoji 和其他非目标字符。
- 起名可选国家、性别、中文风格、固定姓氏及数量 1–50。已知外国姓匹配词库中的中文；未知外国姓出现必填“中文姓氏”，须含汉字且只允许汉字、中文间隔号、空格或连字符。纯汉字自定义姓原样保留，已知日本汉字姓先使用词库中文。俄罗斯随机姓按性别生成；固定姓按输入保留，条件提示不变形。原文、中文、全部分别复制；全部格式为每行 `original（zh）`，中文不重复括注。

## 5. API operationId 与生成类型

本模块无 Backend 请求及生成类型。应用已有 `metaGetMeta` 启动检查属于 app-shell，不是工具请求。工具不读账号、Token 或登录状态；本次没有 OpenAPI 变化。

## 6. 状态模型和数据流

`TextToolPage` 保持 StatefulWidget，按原枚举创建原生面板。输入、条件、错误和结果留在各页面 State；样式沿用当前主题，主题变化不会重建词库或清空输入。每次进入起名页构造一次生成器，build 不重复 JSON 解析。已版本化 JSON 由脚本生成只读 Dart 常量，无新增 asset 声明、JS 运行时或依赖。

三文字工具按已提交 Web 算法迁移，使用 Flutter 自带 characters 的完整 grapheme 分段。竖排保留空行／首尾空格，Tab 转四空格，中文与 Emoji 双格、拉丁字符单格，页间两个 LF；输入最多 10,000 UTF-16 单元，排版最多 100,000 格或 500,000 单元，在创建输出前拒绝膨胀。超限粘贴保留供删改，字段显示限制，不静默吞输入。

## 7. 鉴权、权限和隐私规则

离线计算不触发登录、Cookie、JS bridge、WebView 或授权请求。不记录正文，不注入业务网络客户端。主动点击复制才写系统剪贴板，成功短促提示 1.5 秒，连续点击替换旧提示；失败提供长按恢复提示，不误报成功。旧 WebView 插件和 URL 策略仅作尚未清理的迁移遗留，本页面无调用；本轮不卸载原生依赖或改变 Manifest，以免引入重建及兼容清理范围。

## 8. 本地存储、缓存及失效规则

输入和结果只存当前页面内存，不落盘。退出页面释放 TextEditingController，下一次进入为空。词库随应用代码分发且可离线使用；以后词库或规则更新通过 App 发布，Web 可独立升级但须同步固定样例和版本。

## 9. 加载、空数据、错误、重试和冲突状态

页面没有网络加载／重试。没有结果时不显示占位卡。参数无效、摩斯字符不支持、输出过大或自定义姓缺译名时在生成操作附近显示必要错误，保留输入方便修改。随机去重池不足请求数量时明确显示实际不同姓名数，不重复凑数。

## 10. 跨模块约束

users 只提供入口，app 组合路由；工具服务没有业务 API、上传或持久化依赖。复用 Foundation v7.2.1 令牌、语义返回图标、设置页底色、48dp 触控和安全区。无需 Web 部署才可打开原生工具；临时旧 Web 预览地址不再参与工具运行。

## 11. 测试场景与验收条件

定向覆盖已提交 Web 竖排／摩斯／花体逐字样例、完整 Emoji、空白、UTF-16 上限和结果膨胀；双语固定随机样例、全部国家／性别、未知姓校验、固定俄文姓与日本姓中文、同批去重。Widget 验证原生打开、无 WebView、原生返回、主题保留输入、复制空白、外文译姓必填、超限粘贴和错误恢复；Golden 覆盖每工具明暗、400dp、320dp 双倍字号，并验证键盘出现后生成按钮可达。

本轮先进行定向测试、完整静态分析和本地数据生成核验，由治理任务将已提交候选集成到既有 Debug 会话。负责人仍需真机确认键盘／复制／长文滚动／明暗与译名质量，视觉验收前不宣称可合并。合并前再运行完整本地门禁；当前没有新 APK 或正式发布。

## 12. 已知限制和后续功能

外国词库刻意较小；中文写法供常见人名及角色参考，非真实人物官方唯一译名。固定外国姓时同一性别池可能少于 50 个不同名字，显示实际数量。古风和幻想是自编组合，不声称典籍出处或真实寓意。等宽字体的中文／Emoji 字形宽度仍受系统字体影响。未做 iOS 真机验收；旧 WebView 依赖的后续删除须独立核对消费者和回滚证据。

## 13. 最近审查的契约版本和后端提交

三工具算法与逐字样例基于 Web `2aa7a81ef8d89f86f9447b0fc08e8b115d05b8a2`。双语词库固定提交与每个源文件 SHA-256 记录在 [source.json](../../contracts/toolbox/source.json)，同步入口 `tool/sync_toolbox_data.ps1 -Revision <40位SHA>` 只读取 VPS Git 已提交对象；`dart run tool/generate_toolbox_data.dart --check` 核验源摘要和生成常量一致。Faker 中文词库和温油双语词库许可证保留源码并通过 LicenseRegistry 随 App 提供。
