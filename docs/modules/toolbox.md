# 温油工具箱

状态：`implemented`

Flutter 原生四工具、双语与可选进阶起名已进入开发基线。2026-10-15 负责人确认花体字扩充与进阶时间排序已安装候选可用并授权合并；本批验证、安装和未覆盖项见[验收记录](../architecture/toolbox-fancy-expansion-candidate.md)。

## 1. 模块目标与非目标

工具目录和四工具表单使用 Flutter 原生组件，转换及起名在设备本地计算。进入工具即显示输入，无 WebView、网页初始化或工具网络请求。包含文字竖排、摩斯编码、花体字、十一国及中文古风／幻想起名，以及可选的六国史实参考和文学创作姓名；不新增 Backend API、账号要求、输入历史、收藏或文件权限。

## 2. 用户角色与使用场景

游客及登录用户都可使用。国家包含中国、日本、英国、德国、法国、俄国、美国、意大利、西班牙、韩国、巴西；所有外国结果同时提供原文和中文写法，采用小型常用双语词库，优先译名质量，不自动机器音译。中文姓名本身即中文，不重复显示。

## 3. 页面、入口和导航关系

“我的”个人功能带并列收藏夹、表情包、油卡与工具箱；游客及资料加载／失败时保留独立工具箱入口。原生目录 `/tools` 与详情 `/tools/:toolId` 保持，未知标识回目录。四工具都有单一原生标题和返回，系统返回离开页面，重新进入清空本次输入和结果。

## 4. 用户操作流程

选择工具，输入条件，点“生成”或“转换”，选择文字或复制结果。参数沿用设置页分组行，选择值点开抽屉，数字与固定姓氏行内编辑；正文使用独立输入区，生成动作位于参数组外。工具箱局部标题、字段、操作与结果均使用常规字重，花体输出字形不受此规则影响。

结果内容区按窗口可用高度限制到 45% 且最多 400dp，短结果按内容收缩。超高内容在框内上下滚动并持续显示滚动条；竖排横向超宽也持续显示滚动条，从所选阅读方向开始。复制操作留在结果滚动区外，每次重新生成回到开头，复制仍包含全部结果。

- 竖排默认页宽 10、页高 20、列间 2 个 ASCII 空格、从右向左。宽高范围 1–100，间距 0–10；可改为不含控制字符的最多 20 UTF-16 单元分隔符，空分隔符有效。结果按阅读方向显示起始侧，可横向滚动；复制严格保留空白，不重排或 trim。
- 摩斯支持国际拉丁字母、数字、既有标点与 É，按行转换；解码用空格分隔字符、`/` 分隔单词，未知字符／码组明确报错。
- 花体字提供字体、符号字形、文字特效、边框装饰四类共 49 款，包括伪草书、伪哥特／怪异、故障、气泡伪体、部首、诅咒、上下单点与 Zalgo。选择器分行显示名称与 `Hello Wenyou` 的真实转换样例，标记文字留足行距；切分类选首款并清结果，切样式清结果。Mobile 保留默认粗体，支持中文的逐行括号、星光、羽翼等装饰；逐字组合标记仅用于 ASCII 字母数字，Zalgo 确定性选择且每字最多三个标记。不支持字符原样保留，Emoji、旗帜、键帽、ZWJ 和组合重音完整处理。空输入不生成装饰，空白行及原 CRLF／CR／LF 保留；输出最多 100,000 UTF-16 单元。
- 起名可选国家、性别、中文风格、固定姓氏及数量 1–50。已知外国姓匹配词库中的中文；未知外国姓出现必填“中文姓氏”，须含汉字且只允许汉字、中文间隔号、空格或连字符。纯汉字自定义姓原样保留，已知日本汉字姓先使用词库中文。俄罗斯随机姓按性别生成；固定姓按输入保留，条件提示不变形。原文、中文、全部分别复制；全部格式为每行 `original（zh）`，中文不重复括注。
- “进阶选项”默认收起，展开即使用进阶、收起即回普通，不再另设开关。中国、日本、英国、法国、德国、俄国可展开；其余五国不显示不可用选项。
- 展开后只显示“类型”（史实参考／文学创作）、绑定时期和身份的“风格”，以及该风格确实支持多种结构时的“姓名结构”。不另设时代、姓氏或家族下拉。父称、双名、字／号等仅在相应结构词池中提供；俄罗斯姓形与父称使用同一性别的预录中外文，不现场推导。大字模式的长选项使用标签与当前值上下排列。
- 史实参考的六国风格按真实起始年、结束年由早到晚显示；起止年均相同时沿词库原序。文学创作没有时间阶段，保持原序。排序只作用于显示副本，原词库、默认风格与随机消耗均保持。
- 展开／收起清旧结果，保留普通的中文风格、自由姓及中文覆盖；这些普通参数不参与进阶生成，收起后恢复。切类型或风格清结果并回默认姓名结构；收起清除进阶选择。换国家清掉不兼容普通输入并收起进阶。调试热重载同样关闭并重置进阶临时状态，保留普通输入，旧选择浮层不能恢复隐藏条件。

## 5. API operationId 与生成类型

本模块无 Backend 请求及生成类型。应用已有 `metaGetMeta` 启动检查属于 app-shell，不是工具请求。工具不读账号、Token 或登录状态；本次没有 OpenAPI 变化。

## 6. 状态模型和数据流

`TextToolPage` 保持 StatefulWidget，按原枚举创建原生面板。输入、条件、错误和结果留在各页面 State；样式沿用当前主题，主题变化不会重建词库或清空输入。每次进入起名页构造一次普通生成器；进阶仅通过轻量国家代码集合决定入口，首次展开时才解析进阶 JSON 并在本页复用，build 不重复解析。已版本化 JSON 由脚本生成只读 Dart 常量，无新增 asset 声明、JS 运行时或依赖。

进阶使用独立 `AdvancedNameGenerator`，按共享向量的性别、姓、名、第二名、父称、别号顺序抽样；结构未引用的片段不消耗随机数。第二名从同一性别名字池排除首名原文后抽样。姓名顺序与标点严格使用已提交双语模板，不现场猜测。按完整原文去重并保留首次元数据，最多尝试请求数量的 40 倍，短池显示实际姓名数。普通 v1 与历史 v1 数据、算法、向量保持不变，历史 v1 不再用于当前页面。

三文字工具按已提交 Web 算法迁移，使用 Flutter 自带 characters 的完整 grapheme 分段。竖排保留空行／首尾空格，Tab 转四空格，中文与 Emoji 双格、拉丁字符单格，页间两个 LF；输入最多 10,000 UTF-16 单元，排版最多 100,000 格或 500,000 单元，在创建输出前拒绝膨胀。超限粘贴保留供删改，字段显示限制，不静默吞输入。

## 7. 鉴权、权限和隐私规则

离线计算不触发登录、Cookie、JS bridge、WebView 或授权请求。不记录正文，不注入业务网络客户端。主动点击复制才写系统剪贴板，成功短促提示 1.5 秒，连续点击替换旧提示；失败提供长按恢复提示，不误报成功。原生工具已经替代网页容器，合并前移除无消费者的 WebView 运行插件和测试接口依赖；旧 URL 策略与历史契约保留，不在本次清理兼容协议。

## 8. 本地存储、缓存及失效规则

输入和结果只存当前页面内存，不落盘。退出页面释放 TextEditingController，下一次进入为空。词库随应用代码分发且可离线使用；以后词库或规则更新通过 App 发布，Web 可独立升级但须同步固定样例和版本。

## 9. 加载、空数据、错误、重试和冲突状态

页面没有网络加载／重试。没有结果时不显示占位卡。参数无效、摩斯字符不支持、输出过大或自定义姓缺译名时在生成操作附近显示必要错误，保留输入方便修改。随机去重池不足请求数量时明确显示实际不同姓名数，不重复凑数。

## 10. 跨模块约束

users 只提供入口，app 组合路由；工具服务没有业务 API、上传或持久化依赖。复用 Foundation v7.2.1 令牌、语义返回图标、设置页底色、48dp 触控和安全区。无需 Web 部署才可打开原生工具；临时旧 Web 预览地址不再参与工具运行。

## 11. 测试场景与验收条件

定向覆盖已提交 Web 竖排／摩斯／花体逐字样例、完整 Emoji、空白、UTF-16 上限和结果膨胀；双语固定随机样例、全部国家／性别、未知姓校验、固定俄文姓与日本姓中文、同批去重。历史 v1 的 108 个向量继续保留回归。进阶 v2 覆盖共享向量、六国两类型全部风格／结构／性别、父称姓形一致、第二名去首名、可选结构随机消耗与有限重试。Widget 验证普通参数恢复、展开／收起、国家／类型／风格／结构切换、旧浮层热重载与完整双语复制；Golden 覆盖两类型明暗、400dp、320dp 双倍字号，并验证键盘出现后生成按钮可达。

原生工具基线的历史集成门禁见[集成记录](../architecture/toolbox-integration-acceptance.md)。本轮覆盖 352 个跨端固定花体向量，并独立保留 v1 的 240 向量，检查完整清单预览与边界、分类切换和复制、六国固定时间顺序、明暗窄屏 Golden；实际结果见[验收与集成检查](../architecture/toolbox-fancy-expansion-candidate.md)。按负责人要求，开发阶段先定向反馈，明确验收及合并授权后执行完整入口；发现的临时探针分析告警及四张基线旧图分别通过移出探针、基线复现和补检闭合，首次失败结果保留，不以自动检查代替负责人验收。

## 12. 已知限制和后续功能

外国词库刻意较小；中文写法供常见人名及角色参考，非真实人物官方唯一译名。固定外国姓时同一性别池可能少于 50 个不同名字，显示实际数量。古风和幻想是自编组合，不声称典籍出处或真实寓意。花体与等宽字符的显示和宽度依赖设备系统字体，测试字体画面不证明全部 Android 设备的字形覆盖；负责人已对安装的 Android 候选确认可用，未另行提供逐项手测结果，iOS 未覆盖。

史实参考是有出处片段的角色重组，不代表逐年、各阶层完整覆盖、人口频率、真实家谱或贵族资格。文学创作的风格与字／号等结构是编选及虚构组合，不作为时代、身份或谱系证据；不宣称所有常见片段首次原创。外文采用现代标准拼写，中文为人工编辑参考。不会从 `von`、`de` 等粒子推断贵族身份，或任意为结果授予真实爵位。
