# 社交关系

状态：`in_progress`

## 1. 模块目标与非目标

统一主题与动态收藏、两套私有收藏夹目录、关注、订阅、点赞和拉黑的读写状态。当前已交付主题点赞、主题/动态首次收藏选夹、两类独立收藏夹目录与内容管理、两类订阅、公开用户页关注与拉黑，以及公开/本人关注、粉丝和本人黑名单列表；公开用户动态收藏列表仍是后续切片。收藏表情由独立 stickers 模块负责，本模块不包含推荐算法配置。

## 2. 用户角色与使用场景

游客与登录用户可从公开主页查看服务端允许的关注和粉丝列表，也能看到主题喜欢计数；游客触发主题点赞先登录。普通登录用户可点赞、收藏主题或动态，进入统一收藏页后直接查看默认收藏夹，并通过“主题 / 动态”页签和收藏夹筛选器原地切换内容、新建分类并移动或取消收藏；也可订阅楼主/协作者的官方更新，并按帖内已标记玩家订阅发言。楼主和协作者自动接收更新。登录用户还可管理公开关系及本人黑名单。

## 3. 页面、入口和导航关系

主题点赞、收藏和订阅入口位于 `/threads/:threadId` 固定底部拇指栏，并与发表楼层形成同一可达操作区，不再占用详情题头；未收藏时先打开收藏夹选择 Sheet，已收藏时点击直接取消。玩家发言订阅仍在移动端 Bottom Sheet 中逐人切换。“我的”将“收藏”与关注、粉丝、温油置于同级入口；`/me/bookmarks` 是统一收藏页，顶部“主题 / 动态”只切换两套隔离目录，收藏夹筛选器默认选中该类型的默认夹并就地展示内容。旧 `/me/bookmarks/threads` 与 `/me/bookmarks/moments` 目录路径重定向回统一页；指定夹路径 `/me/bookmarks/threads/folders/:folderId` 与 `/me/bookmarks/moments/folders/:folderId` 继续保留，旧 `/me/bookmarks/folders/:folderId` 继续兼容主题收藏。两类目录都不提供跨收藏夹“全部”。`/me/following`、`/me/followers`、`/me/blocks` 管理关系。本人路径及收藏子路径均保留登录回跳；公开关系和内容仍从 `/users/:userId` 进入，私有收藏夹名称和分类绝不进入公开用户页。

## 4. 用户操作流程

本人收藏页打开后直接展示主题默认收藏夹内容；“主题 / 动态”页签切换两套独立目录，右侧紧凑收藏夹筛选器原地选择默认夹或自建夹，并显示服务端数量。新建、移动或取消收藏成功后同步刷新当前列表和筛选器数量；刷新失败保留可读内容并提供带问题编号的局部重试。主题内容复用 threads 标准信息流卡片，完整呈现默认子贴活跃时间、摘要、安全首图、主题标签、玩家数及其他互动统计；动态收藏复用 moments 双列瀑布卡片，每张卡以 48dp“更多”入口打开当前收藏夹、移动和取消收藏操作，不在窄卡内堆叠管理按钮。

主题与动态详情都以服务端投影初始化互动。首次收藏先读取对应类型目录，默认收藏夹预选；用户也可选择自建收藏夹或在 Sheet 内新建，只有点击“确认”才携带 folderId 发出一次创建收藏写入，不再先写默认夹再移动。目录加载、创建和收藏写入失败都留在原 Sheet 重试；已收藏内容点击仍直接取消。两类目录、模型和计数完全独立，不读取主题目录中的旧动态兼容计数。服务端默认收藏夹保持第一项，新建名称发送前 trim 并校验 1–24 字。主题和动态内容页都以必填 folderId 从首屏读取并建立独立分页状态；移动或取消成功后先采用安全本地移除，再重新读取当前内容页首屏和对应目录计数，禁止从收藏记录 ID 构造游标。订阅控制器独立收敛本人订阅和帖内成员候选：本人订阅成功后即可操作官方更新，候选读取失败只影响玩家入口并可单独重试；官方/玩家订阅都按记录 ID 取消。点赞采用服务端计数；点赞、收藏、订阅、关注与拉黑在写入结果不明时读取对应详情、订阅列表或用户关系投影，只有投影证明目标已达成才同步为完成。点赞/收藏统一复用 Foundation v6.5.1 语义色、选中表面、实心资产和精确在途动作反馈。

## 6. 状态模型和数据流

`ThreadInteractionTarget` 管理详情点赞与快捷收藏，并通过可选投影读取端口采用最新主题详情；`BookmarkFolderCatalogController` 以内容类型为 family key，分别保存主题与动态目录、数量和创建状态。`BookmarkListController` 以必填主题 folderId 为 key；动态侧 `MomentBookmarkListController` 保存当前目录分页、失效 cursor 恢复和移动/取消的唯一在途动作。主题收藏 DTO 在 data 层映射为包含完整主题卡字段与收藏管理 ID 的展示模型，动态本人收藏 DTO 额外保留 `bookmarkFolderId` 与缺失按 true 兼容的 `canInteract`。主题订阅控制器以 `threadId` 为 family key，内部观察稳定 `SessionScope` 并只用当前 `accountId` 过滤本人候选；状态保存当前主题订阅、玩家候选、独立的 `candidateFailure` 与唯一在途目标。`UserRelationTarget` 管理关系写入并可采用公开用户关系投影，`UserRelationListTarget` 管理公开/本人列表。端口由应用组合根按类型绑定，控制器不导入具体 data 仓储。校准中的动作保存中性结果状态和问题编号；所有状态均为 autoDispose，当前不建立跨页面事件总线。

收藏主题卡只接收共享分类展示值，不接收 slug 字符串。分类目录与收藏页分别加载；目录加载中可暂时省略该段，首次失败显示“分类暂不可用”，不会回退显示 `DEDUCTION` 等底层值。

## 7. 鉴权、权限和隐私规则

所有写操作和 `/me/*` 私有列表需要登录；游客进入收藏总览、任一目录或指定收藏夹时先登录并保留完整目标。收藏夹 ID、名称和计数仅属于本人，移动时收藏记录与目标收藏夹都由服务端复核归属，404 不猜测资源是否存在。动态 `canInteract == false` 时禁止新增收藏与移动，但已收藏内容仍可取消；字段缺失按 true 兼容旧服务。游客点赞只进入登录，收藏与订阅入口不显示。主题 capability 或当前成员角色表明楼主/协作者时隐藏订阅控件；普通用户只能选择服务端成员列表中的已标记参与者。收藏列表由服务端过滤已失去访问权的内容，客户端不泄露失效私密条目。

## 8. 本地存储、缓存及失效规则

互动、订阅、收藏与关系列表只存在于 autoDispose Provider；离页、退出或切号即释放。玩家订阅面板记录打开时的会话作用域，切号或退出后当帧隐藏并自动关闭，旧控制器迟到结果不得恢复旧账号操作。主题刷新重新采用详情投影；收藏总览下拉刷新目录和计数，内容页下拉刷新当前首屏与移动所需目录；目录创建、内容移动和取消均建立新的请求世代并丢弃旧响应。收藏夹名称、选择和 cursor 不持久化、不离线排队，也不写进公开内容或全局缓存。

## 9. 加载、空数据、错误、重试和冲突状态

全模块错误遵循[网络与会话](../architecture/networking.md)统一分级：可操作的预期失败只给恢复提示；本机、网络连接、温油站服务与内容处理异常才标注问题环节，只有可核对的服务/内容异常及结果待核对写入显示问题编号。普通页面不展示 HTTP、业务或内部诊断码，Debug 现场诊断可复制安全技术字段。

在途和确认期间禁用同一组按钮并忽略快速重复操作。写入直接成功或最新投影证明目标已达成时采用权威结果；读取到相反状态或读取失败时显示中性的“结果暂时无法确定”并提供刷新，不宣告失败也不重复提交。`40904` 仅在订阅列表精确存在目标记录时收敛为订阅完成，明确权限、参数和内容冲突仍显示失败。统一收藏页的两类目录分别显示加载、数量或失败状态；目录与当前内容首屏使用 Skeleton，首次失败可重试，已有内容后的目录刷新失败使用局部横幅，不遮断当前收藏列表。具体收藏夹空态提示从详情收藏时直接选择该夹。新建弹窗或选择 Sheet 保留输入并显示长度/同名错误，移动到当前分类本地 no-op；`40007` 清空游标并从当前内容页首屏重载。移动或取消写入已成功、后续权威刷新失败时采用安全本地结果并提供刷新。缺少收藏记录 ID 时整页失败，不展示不可管理条目。订阅列表读取失败时整体失败并可重试；玩家候选为空时不显示玩家入口，候选读取失败时保留官方更新控件并在玩家区域提供独立重试，已失效候选在本地阻止写入。

## 10. 跨模块约束

关注、粉丝、拉黑与订阅候选中的具名头像统一回退用户名首个可读字符；匿名或不可用身份才使用中性状态图标。

threads 页面消费主题互动和订阅控制器，moments 提供独立动态收藏目录、分页和管理端口，users 的“我的”页面进入 social 收藏/关系列表；通知计数不因写入伪造。点赞只使用响应计数，主题收藏和订阅只使用响应记录 ID，动态收藏移动使用动态 ID；玩家候选来自 threads 成员端点。主题与动态目录都映射为共享的单一 `bookmarkCount` 展示字段，但来源 DTO 和 Provider 始终按内容类型隔离，原始计数可能高于当前仍可见内容数，客户端不得从已加载页推算或断言相等。收藏页移动/取消不会主动改写仍存活的详情 Provider，跨页刷新仍以服务端为准。

## 12. 已知限制和后续功能

当前未建立跨页面互动事件总线，主题与动态收藏、订阅变化不会主动改写其他仍存活页面。公开用户动态收藏虽已有服务端契约，但移动端尚未接入。后端订阅列表暂无按主题/类型筛选和分页参数，移动端目前必须读取本人完整订阅后过滤；数据量增长前需要补齐契约。后端当前没有收藏夹重命名或删除接口，移动端不伪造这些动作。不做离线关系队列或推荐偏好；视觉动效后置。
