# 标签发现与主题标签管理

状态：`in_progress`

## 1. 模块目标与非目标

提供公开标签主题聚合页，以及楼主/协作者维护主题标签的移动端闭环。当前切片不提供全局标签后台、颜色编辑、批量排序或首页多标签组合筛选。

## 2. 用户角色与使用场景

游客和登录用户都能从首页主题卡片、主题详情或标签主题卡片进入公开标签页。楼主与协作者可从主题管理页搜索、创建、添加和移除标签；普通成员与游客不能进入管理工作台。

## 3. 页面、入口和导航关系

公开路由 `/tags/:tagId` 先读取标签事实，再用稳定 `tagId` 精确筛选公开主题；主题卡片仍进入 `/threads/:threadId`，卡片内其他标签可继续进入对应标签页。受保护路由 `/threads/:threadId/manage/tags` 从主题管理页进入，游客登录后恢复完整目标；`40107` 使用 `/me/security/verify-email?returnTo=...` 恢复原工作台。

## 4. 用户操作流程

公开页并发读取标签详情、动态分类和第一页主题，聚合结果与首页发现共享 `threadsFindAll` 语义，因此不返回已注销楼主的主题，并且卡片只展示唯一首图。接近列表尾部或点击“加载更多”时原样回传 cursor；下拉刷新重新读取三类权威事实。管理页并发读取主题 capability、当前关联与全局候选；搜索输入 320ms 防抖并丢弃旧响应。添加已有标签前读取单条最新版，创建新标签后再关联主题；创建遇到 `40905` 时搜索并确认唯一同名标签，再继续关联。移除前明确说明只解除当前主题关系。

## 5. API operationId 与生成类型

- 公开发现：`tagsGetById`、`threadsFindAll`、`threadCategoriesList`，使用 `TagResponseDto`、`HomeThreadListItemResponseDto` 与 `ThreadsFindAll200Response`。
- 标签检索与创建：`tagsSearch`、`tagsCreate`，使用 `TagsSearch200Response`、`CreateTagDto` 与 `TagsCreate200Response`。
- 主题关联：`threadsFindById`、`threadTagsFindAll`、`threadTagsAdd`、`threadTagsRemove`，使用 `ThreadTagRelationResponseDto`、`ThreadTagResponseDto`、`AddThreadTagDto` 与 `MessageResponseDto`。

## 6. 状态模型和数据流

公开页把标签事实、分类映射、主题页、cursor 和局部失败分离；复用 threads 的主题卡片读模型和映射，使用 `RequestEpoch` 阻止刷新与旧分页结果互相覆盖，并用 `mergeUniqueBy` 按主题 ID 去重。管理状态保存当前标签、候选、规范化查询、搜索标记和单个写操作标识；写入串行，成功只采用服务端返回的标签对象更新本地投影。

## 7. 鉴权、权限和隐私规则

标签详情、搜索和标签主题聚合公开可读，但只返回公开可访问主题。管理页必须登录，并再次以主题 `capabilities.canManageThread` 或 OWNER/COLLABORATOR 角色校验；写操作由后端重复授权。标签创建与关联收到 `40107` 时不清空搜索词，用户验证邮箱后显式重试。错误页不根据标签 ID 猜测私密主题。

## 8. 本地存储、缓存及失效规则

标签页只使用 autoDispose Riverpod 状态和页面滚动状态，不持久化全局标签、搜索词或主题关联。返回公开页会重新建立页面状态；管理写入成功立即更新当前会话投影，下拉或重新进入时读取服务端权威关系。

## 9. 加载、空数据、错误、重试和冲突状态

公开页区分首屏加载、404/停用、空主题、刷新失败和分页失败；`40007` 重新读取标签与第一页。管理页区分无权限、搜索失败和写入失败，保留请求 ID；空响应、重复 ID、错误主题关联、无效名称/颜色和不匹配目标均不能伪装成功。新建的 `40905` 仅在唯一精确同名结果可验证时恢复。

## 10. 跨模块约束

主题条目复用 threads 的公开读模型与发现卡片组件：每项是占满内容列的独立细边框圆角卡片，唯一安全首图在卡片内以整宽 16:9 展示，无图不预留图片舞台；tags 不反向依赖 home。详情和管理入口由 threads 模块提供，验证恢复复用 auth/settings 路由。主题列表与详情中的导航标签使用无图标、无底色、无边框的行内 `#标签` 文本，触控区至少 48dp；管理工作台的编辑 Chip 才使用服务端标签色作低透明度强调，正文和边框继续使用 Foundation 语义色，避免任意标签色破坏对比度。

## 12. 已知限制和后续功能

移动端创建标签只发送名称，不开放任意颜色选择；颜色和描述由服务端现有标签或后台治理。首页暂不提供多标签组合筛选，公开标签页一次只锁定一个稳定 ID。后端当前单标签关联端点没有返回关系 ID，客户端以返回标签事实更新投影并在重新进入时读取完整关系。
