# 只读主题信息流

状态：`in_progress`

## 1. 模块目标与非目标

统一各入口的主题卡片读模型、DTO 映射、卡片组件和公开分类目录。无独立业务页面，不持有主题编辑、订阅、收藏或其他模块的查询状态，不承担内容可见性事实。

## 2. 用户角色与使用场景

游客和登录用户在发现、标签、搜索、公开资料与本人收藏中阅读一致的主题卡片；创作者和管理者读取同一分类目录。

## 3. 页面、入口和导航关系

没有独立路由。卡片通过调用方传入的回调打开主题、作者和标签，模块不读取调用方页面状态。

## 4. 用户操作流程

收藏页布局候选（2026-09-11，待负责人验收）：卡片提供可选 `Widget? trailing` 标题操作插槽，标题保持最多两行；调用方负责动作语义、权限及写入反馈。收藏页在右上角传入 48dp 更多入口，独立于整卡点击；未传入时保持原有标题、封面、摘要及页脚布局，首页等消费者不出现收藏管理操作。

进入消费者页面时读取其内容查询；分类目录并行提供名称。点击卡片进入对应主题；目录不可用、空分类或历史分类按统一规则降级。创作和管理仍由各自流程决定哪些项可选。

## 5. API operationId 与生成类型

各列表通过生成的 `ThreadCoverMediaResponseDto` 读取可空 coverMedia；原 coverImages 保留。Home、Search、ThreadList、BookmarkThread 和 OwnBookmarkThread 的映射共享一个校验入口：源 URL 必须与 coverImages[0] 一致，动画原图不能充当自己的静态 poster。只消费显式动画属性，不看后缀。

`ThreadCoverPreviewVariantResponseDto` 描述可选列表预览的地址、实际宽高和完整文件字节数；previewVariants 为可空数组，最多两项，不改变正文原图地址。

映射只接受安全 HTTP(S) 预览地址、正整数宽高（不超过 800）与字节数（不超过本地下载上限 32 MiB），拒绝原图／poster 冒充预览并去重排序；首页、搜索、本人收藏、用户创建／参演／收藏列表均保留这些元数据。

`threadCategoriesList` 使用 `ThreadCategoryResponseDto`，目录为公开请求。主题 DTO `HomeThreadListItemResponseDto` 的统一映射供消费者仓储复用；主题查询本身仍由消费者持有。

## 6. 状态模型和数据流

`ThreadFeedCardModel`、`ThreadFeedStatus`、`ThreadFeedTag` 与 `ThreadCategory` 是只读展示模型。目录端口由应用根绑定到唯一 API 仓储与缓存装饰器；目录控制器只维护加载状态与最近成功快照。各消费者不再自行调用分类接口或映射分类 DTO。

## 7. 鉴权、权限和隐私规则

分类目录不携带账号凭据。主题数据的权限、拉黑可见性与筛选仍由消费者仓储和查看者作用域负责；卡片不推断额外操作权限。

## 8. 本地存储、缓存及失效规则

应用作用域维护活跃集合，不设并播数量上限。每个播放器使用独占 `ui.Codec`，不进入 Flutter 多帧图片缓存；停止时取消帧定时器和网络请求并释放 codec，解码帧在前台绘制安全点释放，后台直接释放。首帧只限制解码宽度，保留源图比例后由统一 16:9 封面框裁切。

只缓存已激活的动画编码文件；未达到激活门槛的封面不请求动画，也不后台预取。内存 LRU 最多 16 MiB，专用应用缓存子目录 `wenyou-cover-animation-v1` 的磁盘 LRU 最多 128 MiB／128 项，最长七天。内存压力或播放作用域销毁释放编码内存，磁盘文件可在同账号下跨启动复用。目录不可用时本次关闭磁盘复用并继续在线播放，不以旧文件替代网络失败。

内存命中的索引 touch 与网络完整字节的持久化不阻塞字节返回。touch 最多一个在途；待写队列最多两项／32 MiB，超预算仅跳过此次磁盘写入，避免慢磁盘闭包无限持有文件。待写 ticket 在失效、切号及完成后移除，磁盘 remove／clear 仍串行且阻止迟到写回。冷磁盘查找保留原命中路径，可能等待既有队列，不为抢起播而绕过缓存重复下载。

依据 HTTP `Date`、`Age`、传输时间与显式 `max-age`／`Expires` 计算有效期，过期全量重新请求。仅显式 `public` 且有明确有效期的响应进入两级缓存；`private`、`no-store`、`no-cache`、非安全 `Vary`、Cookie、请求或重定向后带查询参数的地址均不缓存，查询参数保守视为签名。资源版本地址变化产生新键。公开文件在新鲜期内可直接复用；此缓存不提供即时撤回已下载公开媒体或离线阅读的保证。

同 URL 在途下载按订阅去重，最后一个订阅撤销才取消共享下载。下载完整且仍属于当前 viewer 后才原子落盘；未完成临时文件不会命中，启动清理孤立文件。索引和文件名只保存 SHA-256、容量／过期／访问时间及散列 owner，读取校验文件大小和内容 hash；损坏文件淘汰后只取一次网络，缓存内容无法解码时也至多一次安全重取。来源端口不向日志传播含完整 URL 的 Dio 异常。

缓存 owner 激活依赖真实 `StartupGate`：`StartupController` 完成会话恢复后才构建播放作用域，临时 guest 不读取或清理上次登录 owner。监听现有 `viewerScopeProvider` 的账号／会话代次及 `contentVisibilityRevisionProvider`；退出、切号和可见性变更同步撤销播放、请求和编码内存，磁盘清理与写入串行，迟到响应不得重新写回旧 viewer。访问令牌正常刷新不改变 scope，不清缓存。新 owner 与持久 owner 不一致时先清专用目录。

共享目录展示订阅仓储的成功快照更新；其他消费者刷新出新名称时，已挂载的目录标签同步更新，不保留第二份永久缓存。释放仓储或展示控制器时关闭各自的更新订阅。

目录只保存在进程内，默认有效期五分钟；普通读取命中有效快照，显式刷新绕过有效期。包括显式刷新在内的并发读取共用一个在途请求；失败不覆盖最近成功快照，锁释放后可再次显式重试。发现刷新、标签加载、创作引导和主题管理进入均要求刷新，目录展示初载可复用有效缓存。公共目录不因账号切换而清空。

## 9. 加载、空数据、错误、重试和冲突状态

旧后端缺少元数据、外部未知来源、历史动画无可信首帧、poster 下载或解码失败时保持占位，不探测或回退原图。首帧失败会撤销已有租约，旧 URL 的加载回调不能激活新封面。详情保留正常内容入口；本阶段不回填历史媒体。

过滤停用项，校验非空 ID、slug、名称以及唯一性，再按服务端顺序值排序。未知旧 slug 显示“历史分类”，无分类显示“未分类”；加载时不伪造名称，首次失败可显示“分类暂不可用”。目录刷新失败保留已有展示；创作/管理按自身错误状态明确重试。管理页缺失的当前旧分类只能只读保留，不能重新选用。

## 10. 跨模块约束

消费者只使用根 facade：`thread_feed_models.dart`、`thread_feed_mapping.dart`、`thread_feed_widgets.dart`、`thread_feed_catalog.dart` 和仅导出端口的 `thread_feed_catalog_ports.dart`。data 仅依赖目录端口，不反向读取目录控制器。模块不依赖 threads、social 或其他 feature，避免只读卡片建立循环。视觉完全复用 Foundation v6.9.0，无新增视觉 Token 或图标实现。
