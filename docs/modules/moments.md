# 动态

状态：`in_progress`

## 1. 模块目标与非目标

实现独立于主题帖的短内容动态：发现/关注/用户信息流、按独立收藏夹分页的本人收藏双列瀑布流、详情、纯文本发布编辑、最多九图、本机自动草稿、删除、点赞、收藏、两层评论、评论图片、收藏表情、站内传送门与社区举报。动态正文不解析通用 Markdown，只按后端 v1 黄金契约激活合法站内坐标；不做视频、话题或离线自动发布。

动态与评论选图后立即显示本地预览，只有实际工作超过 300ms 的图片才遮罩转圈，排队的多图保持清晰；失败图点按打开操作，评论已有图时再次点添加只显示短暂单图提示。发布等待 3 秒后才展开剩余数量与取消；就绪和成功新增图片不弹提示，也不占整行展示上传阶段。

## 2. 用户角色与使用场景

游客可浏览发现流、用户动态、详情与评论；登录用户额外查看关注流和本人动态收藏夹，发布、编辑或删除自己的动态，点赞/收藏，并发送纯文本、单图或单个收藏表情评论。服务端返回的 `canEdit`、`canDelete`、动态 `canInteract` 和评论 `canDelete` 是最终权限事实；`canInteract` 缺失按 true 兼容旧服务。

## 3. 页面、入口和导航关系

动态是四分支应用壳的 `/moments` 主分支，分为“发现”和“关注”；顶栏只提供全站搜索入口，不重复展示动态收藏入口。在任一主导航分支点击底栏中央发布动作都会先打开轻量选择器，选择“动态”后进入受保护的 `/compose/moment`。详情使用公开 `/moments/:momentId`，动态评论通知可附加 `?comment=:commentId` 精确定位；编辑使用受保护的 `/moments/:momentId/edit`。本人动态收藏从“我的”进入统一 `/me/bookmarks` 页面，以“主题 / 动态”页签切换类型并直接展示默认夹；指定收藏夹仍使用 `/me/bookmarks/moments/folders/:folderId`，旧 `/me/bookmarks/moments` 与 `/moments/bookmarks` 重定向到统一入口。公开用户主页通过 `/users/:userId/moments` 读取该用户动态。全站搜索的动态 Tab 以稳定 momentId 进入同一详情。

Foundation v7.1.0 时间呈现候选／待验收：普通内容不足 72 小时保留相对时间，满 72 小时和未来时间显示同年短日期或跨年完整日期；读屏提供完整日期，不含时分。安全、审计、账务、预约及到期时刻保留精确时间。原始时间戳不变。普通内容时间共用一个前台分钟刷新源，恢复前台立即更新，没有消费者或进入后台时停止；不为每行创建计时器。

## 4. 用户操作流程

自适应阅读滑块（2026-09-26 候选／待负责人验收）：主题详情与独立楼中楼移除顶栏快翻按钮及操作卡，动态详情使用同一入口。普通阅读显示不拦截正文的细条，主阅读列表一次明确快滑后非线性展开，当前正文手势继续，下一次触摸可抓取；停稳短暂停留后收细、淡出。两态沿同一完整可用阅读高度移动并保持中心映射，避开实际吸顶栏、发表入口及系统手势区。只有展开命中区接管触摸；短点按被消费且不弹菜单，轨道点按继续正文操作。尺寸、阈值、时序与无障碍以正式 Foundation v7.2.0 的 `WenyouAdaptiveReadingScrollContract` 为事实源。

抓取立即停止惯性并以实际位置和抓取偏移建立基准，正文直接跟手；正常松手完成最后输入并停止末端跟随，取消丢弃未绘制输入。按住已加载末端时沿用既有分页／图片增长，离开末端和松手即停。仅拖动时显示实际正文、楼层或回复附近；未完整加载只称“已加载范围”，重试仍在原列表入口。无可滚动内容隐藏。换子贴、筛选、排序、账号、编辑器、键盘、路由覆盖和取消均清理旧动作。TalkBack 持续提供可调滑块，键盘焦点保持显示并支持按视口增减与首尾导航；减少动态效果时直接切形态。新交互详见[自适应滑块验收](../architecture/adaptive-reading-scroll-acceptance.md)，旧版真机结果仅作[历史参考](../architecture/vertical-quick-scroll-acceptance.md)。

动态详情滑块覆盖正文和当前已展开评论，保持显式加载更多、展开楼中楼及原失败重试；发现／关注瀑布信息流保持原样。

全屏图片图集候选：正文完整配图先本地显示，再验证图集权限和版本；一级评论与根评论回复各为独立图集，按阅读顺序双向加载。动画保留原播放失败状态，只有当前图片播放；切到另一评论后收藏使用该评论及媒体 ID。见[图片图集](../architecture/image-gallery-acceptance.md)。

评论保持单图：没有图片时点击原上传图标选择图片；已有图片再点击只显示 2.5 秒“评论只能添加一张图片”横栏提示，不打开相册、不上传、不替换，需先移除再添加。界面不常驻单图说明或“更换图片”按钮。横栏复用全局提示外观，归属当前评论弹层，按实际弹层、键盘和系统安全区定位；空间不足时限制高度并允许滚动，不抢编辑焦点。重复点击重置同一条提示计时，移除、切换表情、开始发送和关闭评论会清除提示。取消、失败保留当前文字，已移除的旧图片不会恢复；原有附件失效代次、上传重试身份与同步发送锁保持。

2026-09-21 能力一致性候选／待负责人验收：本模块输入边界、附件生命周期或权限入口与固定后端契约对齐；已证实偏差、逐入口证据、回归及未验证边界见[能力一致性盘查](../architecture/capability-consistency-audit.md)。长度按后端 Unicode 码点计算，编辑光标仍使用原有 UTF16 偏移；密码保持原始内容，用户名与标签白名单不扩展。

收藏管理面板候选（2026-09-11，待负责人验收）：动态卡片保留原 48dp 更多位置，底部面板与主题收藏共享，只读显示当前收藏夹和“移动到其他收藏夹 / 取消收藏”操作。关闭不写入；`canInteract == false` 禁止移动并保留原因，取消仍可执行；在途禁用管理并在当前项显示加载状态。移动失败仍留在选夹面板，取消失败仍保留列表并反馈错误。

动态自建收藏夹重命名／删除候选（2026-09-13，待负责人验收）：本人统一收藏页选中动态自建夹后可从顶栏打开管理面板。重命名预填并选中原名，trim 后 1–24 个 Unicode 字符；删除确认告知收藏迁移至默认夹而内容保留。删除成功使用响应返回的动态默认夹 ID 切换当前目录并刷新；失败保留当前夹与内容。功能依赖 Backend PR #20 合并发布，当前公网尚未提供新接口。

发现流与关注流统一按最后一条未删除评论时间倒序，无评论时按动态发布时间倒序；点赞、收藏、加油和编辑不改变位置。顶部“发现 / 关注”使用共享线性内容页签和底部选中线，支持点按或在信息流内容区左右滑动切换。发现、关注、收藏和用户信息流以 12dp 间距双列瀑布呈现，卡片只展示封面、两行标题、作者和点赞，正文、评论、收藏与加油进入详情处理。图片封面按服务端宽高预留比例，过长竖图最低收束到 3:4，多图显示数量；列表只使用静态派生图：GIF 或 animated 图片仅 thumbnail，其余图片按 feed、thumbnail、medium 回退；任何列表均不请求、预取或回退到原图，缺失或失败显示占位。纯文字封面固定 3:4，使用 Foundation 展示字体与服务端主题色，标题只在封面中出现一次。独立列表下拉刷新回到首屏，接近底部或按钮加载下一游标；分页追加、反复滚动到底或回顶时保持连续双列和完整滚动范围。嵌入“我的”动态页签时，列表加入本人主页的统一滚动链，不重复安装刷新层。

发布页依次展示图片区、2～40 字必填标题和最多 1000 字选填正文，底部安全区只保留全宽“发布”或“保存”主操作。无图时图片区仅显示一个 48dp“添加图片”入口；选中后才显示缩略图、剩余数量和继续添加动作。一次可选当前剩余容量，不打开裁剪页；待完成图片采用稳定标识原位更新，可分批继续添加、排序、选择封面和逐张移除；上传传输与处理等待由共享流水线独立限流。300ms 后才显示图片内进度，只有文件传输展示百分比；失败在单张图片上提供重试或移除。正文使用只支持普通文字与传送门原子的轻量输入器，不带格式工具栏或字数提示。标题、正文、封面、图片顺序与已持久化到私有目录的待完成图片 500ms 防抖写入本账号草稿；重新进入自动恢复，普通草稿离页时明确选择保存或不保存。发布待确认时锁定内容，只能重试确认或保留后退出。点击发布后固定当前内容并等待图片就绪，期间可取消发布；失败与等待超时取消发布意图，处理后需再次点击。离开或重启不自动发布，恢复已有媒体身份时先续查。无图时由服务端返回确定性文字封面主题；编辑提交当前 `version`，删除需二次确认。

详情先以完整标题建立阅读层级，再展示作者、图片轮播和纯文本正文；正文后以单行四等分互动栏依次展示点赞、收藏、评论和累计加油，每项只保留 Foundation 语义图标与普通字重紧凑数字，不常驻动作名称、单位或解释文字。标题/正文保留内边距，轮播只保留页面级外边距。静态轮播与评论图片继续优先 medium，再回退 thumbnail 和主图；多图在固定舞台内横滑切换。动态图片按 animated 或 contentType 识别，只在详情当前轮播页且图片可见时播放原图；同屏可见评论和楼中楼图片、动态表情全部播放。GIF 静止时只取 thumbnail；动态表情的 mediumUrl 可能与动画 url 相同，静止时固定使用 thumbnailUrl。点按图片或评论表情进入共享全屏原图页，支持图库横滑、双击或捏合缩放、平移、未放大时下滑关闭和加载失败后切换候选。右上角“图片操作”始终针对当前图片：Android/iOS 可把主图原始字节保存到系统相册，登录且表情能力开启时还可按动态或评论的稳定 ID 添加到表情收藏；进行中禁止重复操作，失败留在当前图片并可重试。全屏只播放当前图片，详情底层全部暂停；切图、离屏、路由被覆盖、App 非前台时卸载动画监听，恢复可见时允许从头播放。动画失败显示静态预览和“重试播放”，错误在当前详情及其全屏页间保持，切图、离屏或前后台不会自动重试；显式重试或媒体身份变化才解除。保存动态图只使用原始字节，失败不保存静态缩略图代替原图。当前不提供分享或批量保存。正文与评论只把合法站内坐标渲染为可点传送门，普通 Markdown、外部地址、非法邀请和歧义查询保持完整字面文本。

详情首次收藏先打开动态收藏夹选择 Sheet，默认夹预选且可内联新建；用户确认后只发一次收藏写入，已收藏时点击直接取消。`canInteract == false` 时禁止新增收藏，既有收藏仍可取消。非本人动态可从互动栏的加油图标与累计数字进入现有加油流程；本人动态保留同位置只读累计，维持四项布局。点击互动栏的评论图标与数字会直接唤起发表评论输入，右下角紧凑悬浮入口保留为同一操作的就近入口；举报位于详情顶栏。评论主列表默认最新，评论总数与“倒序 / 正序”直接排序同行；顶层评论按所选顺序展示，内嵌回复保持服务端正序。尚有未展示回复时使用与主题帖相同的普通字重、弱化前景“展开楼中楼（N 条）”入口和方向图标，命中区不小于 48dp。评论文字长按进入系统选字，作者、时间和非文字区域长按才打开操作菜单。评论输入使用唯一的私聊式轻量 dock，打开后自动聚焦，文字独占第一行，图片、表情和发送位于下方操作行。点击外部暗区或系统返回收起并在本页内保留未发送内容；评论最多 500 字，可带一张图片或一个收藏表情。详情按来源返回；无来源栈时返回动态列表。

评论正文文字长按进入系统选字，作者、时间、空白、图片、表情和传送门等非文字区域长按打开帖子楼层同款中央遮罩窗口，图片同行空白等整层留白也属于可长按区域。评论作者行只有头像点按进入个人主页，用户名、等级、时间及同行空白不触发导航，与主题帖楼层保持一致。窗口显示评论或回复操作标题，以对称栅格按权限展示复制、删除和举报，暗区阻断背景点击，点按暗区、显式关闭入口或系统返回均可退出。点击评论仍直接回复，菜单不再重复提供回复；评论输入继续使用原有 Sheet，排序按钮不打开 Sheet。

顶部“发现 / 关注”除点按页签外，也支持在信息流内容区左右滑动切换相邻栏目。内容按 Foundation standard 180ms 沿方向轻量入场，已访问栏目在当前页面生命周期内保持列表、分页与滚动状态，返回时不重新请求首屏；短滑与首尾越界保持当前栏目，瀑布流纵向滚动和下拉刷新继续由列表处理，减少动态效果时瞬时切换。

## 5. API operationId 与生成类型

- 信息流与详情：`momentsList`、按必填 folderId 调用的 `momentsBookmarks`、`userMomentsList`、`momentsDetail`。
- 搜索读模型由 search 模块调用 `searchSearchMoments`，映射为同一 `MomentCard`。
- 内容写入：`momentsCreate`、`momentsUpdate`、`momentsRemove`。
- 收藏目录与互动：`momentsBookmarkFolders`、`momentsCreateBookmarkFolder`、`momentsBookmark`、`momentsUnbookmark`、`momentsMoveBookmark`；首次收藏携带 folderId。
- 收藏夹管理候选新增 `momentsRenameBookmarkFolder`、`momentsDeleteBookmarkFolder`；删除响应返回实际接收全部收藏的默认夹 ID。
- 评论：`momentsCommentsList`、`momentsReplies`、`momentsCreateComment`、`momentsRemoveComment`；`momentsCommentAuthors` 保留契约与仓储映射，但详情页不再请求作者候选。
- 定位上下文：`momentsCommentContext` 按稳定 commentId 返回目标所在主评论、精确目标和当前可见回复数；第 17 个 Moments operationId 已接入通知定位主闭环。
- 图片收藏表情复用 stickers 模块的 `stickersImportMomentImage` 与 `stickersImportMomentCommentImage`，分别提交 `momentId + mediaId` 与 `momentCommentId + mediaId`。
- 社区举报：reports 模块调用 `reportsCreate`，分别提交 `MOMENT` 或 `MOMENT_COMMENT` 目标。
- 主要生成类型：`MomentCardResponseDto`、`MomentDetailResponseDto`、`MomentMediaResponseDto`、`MomentRootCommentResponseDto`、`MomentCommentResponseDto`、`MomentStickerResponseDto`、`CreateMomentDto`、`UpdateMomentDto` 与 `CreateMomentCommentDto`。

## 6. 状态模型和数据流

阅读页保留 `ReadingProgressViewport`，共用 `ReadingQuickScrollController`、速度采样器和可见性计时。仅主列表真实手指位移参与快滑识别；反向重置采样，程序滚动、深链、布局、图片撑高、横向轮播和下拉回弹不唤醒，惯性只延长已展开状态。动画只更新滑块，不重建正文。拖动轨道与映射冻结，每帧合并最新输入；保留首次懒布局收缩校正、可见锚点和末端跟随。抓取及键盘导航解除深链自动对齐，自动显隐不导航。可见锚点只登记已布局内容；无全量预布局或额外图片预取。

动态收藏夹目录与主题目录按类型独立；统一目录控制器用动态专属仓储执行改名／删除。删除先采用服务端响应中的 `destinationFolderId` 切换当前内容页，再刷新目录，不能假定固定默认夹 ID。

动态信息流与详情的点赞、收藏立即投影状态、计数和收藏夹归属；同一动态写入互斥，不同动态可各自提交。失败仅恢复本次操作的字段，不能覆盖同时发生的评论或其他动态操作；早于点按的刷新不能覆盖更新后的互动。超时先读取动态详情校准，只在目标得到证实时提示成功。动态收藏夹的移动/取消在提交时立即移出当前目录，明确失败恢复位置与分页；计数仍由独立目录校准，不以当前页长度推算总数。选择收藏夹后关闭弹层，失败在原页面反馈。已于 2026-09-13 获负责人确认通过并授权合并，见 [乐观更新验收](../architecture/optimistic-interactions-acceptance.md)。

完整展示（负责人已验收）：动态／回复图片与表情详情、全屏及默认保存使用完整 display；动态列表继续静态海报，详情继续原有可见性／轮播／后台规则。动态编辑加载、上传结果和本地草稿往返携带展示描述，原 mediaId／URL 保持。批量上传处理中窗口结束显示可继续查询，同一任务续查不重复上传。见[全场景验收记录](../architecture/animation-webp-all-surfaces.md)。

`MomentFeedController` 以 main/user target 隔离公开列表、游标、刷新、分页和单条互动写入；本人收藏由 `MomentBookmarkListController` 以必填 folderId 建立独立分页，保留本人收藏 DTO 的 `bookmarkFolderId` 与 `canInteract`，移动/取消后本地移除并权威刷新。`BookmarkFolderCatalogController` 通过动态专属仓储读取/创建目录，不与主题目录混用。`MomentMedia` 保存主图、显式派生 URL、contentType、animated 和尺寸，单独提供列表静态候选与详情播放预览；原有编辑器候选保持不变；仓储和搜索映射器对所有非空 URL fail-closed。`MomentFeedList` 通过滚动通知触发接近底部分页，因此独立页面可使用自身滚动位置，嵌入本人主页时也可继承父级滚动协调器；卡片与全宽尾部状态由同一懒加载瀑布流维护几何，稳定 Key 在刷新重排和分页追加时恢复既有卡片位置。`MomentDetailController` 同时读取详情与主评论；切换顶层顺序只重载一次主评论首页并清空原 cursor 与已展开回复。根评论内嵌回复与楼中楼分页均保留后端返回顺序，楼中楼分页固定请求 `OLDEST`。带评论坐标时，独立且按会话隔离的 `momentCommentContextProvider` 并行读取上下文；展示投影按 ID 去重，以上下文目标覆盖重复项，将缺失主评论按当前顺序注入，并把目标回复按最早顺序展开。上下文不改写普通列表 cursor，也不触发 `fetchComments` 或 `fetchReplies` 分页扫描。`MomentComposerController` 负责创建幂等键、编辑版本、冲突重试和删除确认结果；动态仓储与本机草稿存储端口位于 `moments/application`。用户在 `40002` 后选择“保留我的内容”时，控制器先读取最新详情和权限，再以最新 `version` 重交当前表单；选择“使用最新内容”时清除本机草稿并重载详情。动态发布页为未完成图片保留本地输入、独立任务状态和完成结果，各图片就绪后按稳定标识原位替换，不占用后续图片传输名额。评论仍按页面实例消费单图上传任务。

信息流与详情的点赞/收藏状态记录精确在途动作，只锁定对应控件并保留旧选中投影，直到服务端回包覆盖。详情互动栏始终展示四个统计值并使用 Foundation 紧凑格式，TalkBack 保留动作名称、选中状态、单位和服务端精确原值；评论项暴露发表评论按钮语义，本人动态的加油累计保持只读语义。可写消费者统一使用 Foundation v6.9.0 的点赞/收藏语义色、透明选中容器和官方实心图标变体；搜索等只读消费者始终显示中性线性图标，不暴露按钮或 toggled 语义。

## 7. 鉴权、权限和隐私规则

发现、用户列表、详情与评论读操作允许游客；可选认证请求仍通过普通拦截器发送，以便登录用户取得 viewerLiked/viewerBookmarked 和权限投影。关注、收藏目录/内容及所有写操作要求登录，游客从当前安全路径进入登录回跳。动态编辑/删除只消费服务端 capability；收藏相关 `canInteract == false` 禁止新增收藏和移动，但允许取消，字段缺失按 true。其余点赞、评论与加油对该字段的消费仍是独立债务。举报入口用同一 `canEdit` 排除本人动态，评论则用当前 JWT `sub` 做保守本人隐藏，最终目标可见性和本人关系都由服务端复核。客户端不猜测隐藏动态、评论或被拉黑关系。预签名 URL、图片字节、评论正文和幂等键不落日志；评论正文与评论幂等键不持久化，动态创建幂等键仅随账号隔离的本机快照保存。

## 8. 本地存储、缓存及失效规则

开发预览按 Backend runId 隔离 Token、偏好、Drift 草稿／待确认操作、图片草稿和缓存；同名批次 reset 后使用新命名空间。原线上路径与数据保留，不向预览迁移身份或待提交操作。网络与上传先验证当前批次实际资源身份；预览仅 Debug 启用。详见 [持续 Debug](../live-debug.md)。

信息流、详情、收藏和评论定位缓存依赖统一 `ViewerScope`；切号或拉黑关系变化后旧请求不得回写。发布草稿只依赖账号会话，不因内容可见性版本变化而清空。

动态列表、评论、排序、游标、上传进度和评论幂等键只保存在当前 Riverpod/页面生命周期；主分支按需构建“发现 / 关注”，已访问栏目在同一页面生命周期内继续挂载，栏目切换不释放其列表状态。评论定位上下文同样不持久化，按 momentId、commentId 和账号会话分区，详情下拉刷新以及评论创建/删除成功后失效重读。评论输入草稿也只保留在当前详情页内存，不写 SharedPreferences 或云端。发布/编辑表单例外：控制器通过 `MomentDraftStore` 按账号与新建/稳定 momentId 分区，在 Drift v1 现有快照表保存标题、完整正文、已完成媒体的安全 URL/尺寸、封面和顺序；不保存源字节、未完成批次、预签名 URL 或 Token。500ms 防抖、失活/暂停和离页保存串行提交，删除排在旧保存之后，成功提交后迟到保存不得复活草稿。首次创建把快照与冻结的规范化载荷、UUID 原子保存到快照/待确认表；超时、5xx 或未知结果时锁定标题、正文与图片，仅由用户“重试确认”重交原载荷；已经确认成功但本机清理失败时保持只读，重试只清理本机记录。重新进入只恢复本账号内容，不自动发布；确认成功后可以进入已发布动态编辑。待确认内容离页只允许保留，不提供丢弃或重新开始。普通草稿自动恢复且可撤销；明确保存、删除、采用最新内容或放弃后清除。旧 SharedPreferences `moment.compose.draft.v1:*` 无法证明账号归属，原样保留但不读取、不恢复、不迁移。图片使用共享安全 HTTP(S) 缓存；发布、编辑、删除和通知返回后失效相关信息流/详情。

## 9. 加载、空数据、错误、重试和冲突状态

反馈简化（2026-09-09 负责人验收通过，源码 `15d4b6b`）：评论删除确认只询问是否删除，成功删除当前评论目标时结束其路由定位；不可见目标使用普通说明，上下文加载或失败不再注入历史正文，临时错误仍可重试。动态收藏移动失败只在收藏夹选择弹窗内展示，取消收藏失败在对应操作单独反馈，避免全局监听重复报错。真实页面覆盖删除取消／成功、旧链接／临时失败、移动失败与取消收藏失败。

保存或删除已成功但本机草稿清理失败时保留只读页面，主操作改为“重试清理”；再次操作只清理本机记录，不重复提交保存或删除。

拉黑或解除后清除动态流、详情、回复定位和收藏的旧可见性投影。

全模块错误遵循[网络与会话](../architecture/networking.md)统一分级：可操作的预期失败只给恢复提示；本机、网络连接、温油站服务与内容处理异常才标注问题环节，只有可核对的服务/内容异常及结果待核对写入显示问题编号。普通页面不展示 HTTP、业务或内部诊断码，Debug 现场诊断可复制安全技术字段。

信息流空态只保留当前事实标题，不教学下拉、关注或发布。

发现、关注、收藏和用户信息流分别覆盖双列首屏骨架、空、首屏失败、刷新失败和分页失败；接近底部自动加载并保留显式“加载更多”后备入口，`40007` 丢弃失效 cursor 并回到首屏。详情首屏使用单列详情结构 Skeleton，区分不存在与网络失败，已加载内容刷新失败时继续保留可读事实。评论定位加载时在排序行后显示“正在定位评论…”；上下文 404 或 `40415` 保留动态与普通评论并显示“目标评论已不可见”，不提供无意义重试；网络或 5xx 失败只为定位请求展示安全文案、问题编号和“重试定位”。`40002` 显示“这条动态刚刚更新了”，并明确提供“保留我的内容 / 使用最新内容”，不静默覆盖本机输入；其他 `40415` 收敛为动态或评论已不存在；不明确创建/评论失败保留原输入与同一幂等键。上传失败只在当前缩略图提供重试、移除；其他图片继续准备。等待发布锁定输入，取消恢复编辑；退出保存正文、私有文件与已知媒体身份后暂停客户端任务，忽略迟到结果。

动态评论和回复的复制结果只由系统剪贴板写入决定；复制时保留普通正文，只把传送门、提及、骰子和规范表情等行内原子替换为阅读态可见 label，不写入目标地址或协议节点。写入成功后显示短确认，确认提示异常不显示“复制失败”也不重复复制，只有写入本身失败才保留关闭与重试任务。

## 10. 跨模块约束

动态瀑布流卡片和骨架外框遵循 Foundation v7.1.2：圆角 10dp，双列横纵卡间距 8dp；封面随外框裁切，详情弹窗与操作浮层按面板语义使用 12dp 圆角。

本模块页面排版统一遵循[移动端视觉基线](../architecture/visual-baseline.md)中的 Foundation v6.9.0 语义文字角色，不自定义字号或直接依赖 Material 字体槽位。

动态作者头像、发布时间与互动计数复用 Foundation 共享身份和格式化组件；短时间同时提供完整时间语义，紧凑计数的操作语义保留服务端原值。

media/application 提供相册与上传端口、唯一任务状态、取消、失败和同文件重试；动态和评论以图片内简短状态展示任务进度，完整诊断阶段仍由共享上传任务保存。moments presentation 不直接导入 media/data 或 Dio，只消费完成结果并维护最多九图、封面顺序及评论图片/表情互斥。stickers 提供用户私有收藏选择器；notifications 只传稳定 momentId 和可选 momentCommentId；users 暴露公开用户动态入口；search 复用动态卡片；wallet 维护加油幂等写入；reports 管理举报。动态正文和评论始终是纯文本，不进入 Markdown/Quill Codec。合法站内坐标由共享阅读组件渲染成 Foundation v6.9.0 传送门胶囊。视觉只消费 Foundation v6.9.0 Token、元素契约、语义图标与图片角色；发现、关注、收藏和用户信息流显式消费双列瀑布流领域例外，详情保持单列和不超过 600dp，独立操作命中区不小于 48dp。
