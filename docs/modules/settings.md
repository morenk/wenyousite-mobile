# 设置

状态：`planned`

## 1. 模块目标与非目标

承载账号安全、终端会话、隐私、关于和开发环境信息。V1 不含暗色主题、实验室或远程配置控制台。

## 2. 用户角色与使用场景

游客查看关于和环境信息；登录用户管理资料隐私、密码、邮箱、终端、退出和注销。

## 3. 页面、入口和导航关系

“我的”进入设置总览；账号安全与隐私是二级分组；开发信息页显示应用版本、API 地址和已验证契约，不显示凭据。

## 4. 用户操作流程

修改项读取服务端事实并确认保存；破坏性退出/注销二次确认；关于页可复制请求排障所需的非敏感版本信息。

## 5. API operationId 与生成类型

- `usersGetMe`、`usersUpdateMe`、`usersDeleteMe`。
- `authChangePassword`、`authRequestChangeEmailCode`、`authVerifyChangeEmail`、`authListSessions`、`authRevokeSession`、`authLogout`。

## 6. 状态模型和数据流

每个设置表单独立保存初值、编辑值和提交状态；环境信息来自 `AppEnvironment` 与最后一次兼容检查。

## 7. 鉴权、权限和隐私规则

敏感操作重新验证规则以服务端为准。环境页绝不展示 Token、密码、验证码、完整隐私资料或预签名 URL。

## 8. 本地存储、缓存及失效规则

非敏感 UI 偏好可进 SharedPreferences；账号设置服务端为权威。切号清表单和私有缓存；退出交由 SessionController 原子清理。

## 9. 加载、空数据、错误、重试和冲突状态

表单提交防重复；验证码限流显示剩余时间；撤销当前终端后立即失效会话；注销网络失败不得假装服务端已注销。

## 10. 跨模块约束

认证生命周期由 auth 实现，资料由 users，头像由 media；设置只编排页面，不复制仓储逻辑。

## 11. 测试场景与验收条件

- [ ] 游客能查看关于，登录用户看到完整分组。
- [ ] 隐私、密码、邮箱和终端会话操作可恢复且状态正确。
- [ ] 退出清本地会话；注销只用一次性账号人工验收。
- [ ] 开发信息准确且无敏感数据。

## 12. 已知限制和后续功能

不做暗色主题、动态实验开关和多账号管理；视觉设置在后续里程碑讨论。
