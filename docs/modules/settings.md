# 设置

状态：`in_progress`

## 1. 模块目标与非目标

承载账号安全、终端会话、资料隐私、黑名单入口、关于和开发环境信息。当前已交付“我的”资料隐私编排、安全退出、登录终端管理与黑名单管理入口；V1 不含暗色主题、实验室或远程配置控制台。

## 2. 用户角色与使用场景

游客从“我的”进入登录；登录用户当前可管理资料隐私、本人关系列表、黑名单、活跃登录终端和退出，密码、邮箱、注销及关于信息后续接入。

## 3. 页面、入口和导航关系

“我的” `/me` 当前直接展示本人总览、资料和公开范围表单，并可进入自己的公开主页、本人关注/粉丝、`/me/blocks` 黑名单页及 `/me/security/sessions` 登录终端页。密码、邮箱、注销与关于后续拆为二级页面；任何开发信息都不得显示凭据。

## 4. 用户操作流程

资料和公开范围先读取服务端事实，只提交变化字段并采用服务端响应；黑名单读取服务端列表，取消拉黑成功后才移除，失败保留条目与请求 ID。终端页按当前优先、其余最近活动时间倒序展示平台与三个时间；当前终端只读，其他终端二次确认后按稳定 ID 撤销，成功才移除，失败保留条目。当前账号退出仍需二次确认，服务端失败时可重试或再次确认仅清本机。注销与关于页尚未接入。

## 5. API operationId 与生成类型

- 已接入：`usersGetMe`、`usersUpdateMe`、`usersFollowBlocks`、`usersFollowUnblock`、`authLogout`、`authListSessions`、`authRevokeSession`。
- 后续：`usersDeleteMe`、`authChangePassword`、`authRequestChangeEmailCode`、`authVerifyChangeEmail`。

## 6. 状态模型和数据流

本人资料由 users 的 autoDispose 控制器读取；用户名与资料隐私是独立编辑动作，共用防并发提交状态。表单保存初值、编辑值和局部错误，成功后使用 PATCH 响应重置。黑名单由 social 的 autoDispose 列表控制器管理，终端列表由 settings 的 autoDispose 控制器管理，当前账号退出继续由 auth 的独立控制器管理。终端撤销串行执行，不允许用页面刷新覆盖在途结果。

## 7. 鉴权、权限和隐私规则

`/me` 只在认证状态请求私有资料；`/me/following`、`/me/followers`、`/me/blocks` 与 `/me/security/sessions` 都受路由鉴权，游客先登录并保留安全回跳。用户名冷却、冲突和限流以服务端为准。终端界面只根据 `platform` 映射平台文案，禁止读取或展示已废弃的 `deviceInfo` 原始 UA；其他页面只显示脱敏邮箱，不展示 Token、密码、验证码、敏感凭据或预签名 URL。

## 8. 本地存储、缓存及失效规则

资料、关系列表、终端列表和表单不持久化，账号设置服务端为权威；页面销毁、切号和退出释放私有状态。终端撤销成功后仅按稳定 ID 从当前列表移除，下次进入重新读取；当前账号退出交由 SessionController 原子清理。

## 9. 加载、空数据、错误、重试和冲突状态

表单提交防重复，未变化不发请求；失败保留输入、旧资料与请求 ID。黑名单与终端读取均提供加载、空、失败、重试和刷新；写入串行执行并在失败时保留列表。终端限流使用全局 `42900` 友好提示，未知平台降级为“其他终端登录”，空撤销响应不伪装成功。已有简介因当前 DTO 不支持 null 而不能清空，客户端明确提示。当前账号退出失败保留会话并提供本机后备；验证码与注销状态后续实现。

## 10. 跨模块约束

认证生命周期由 auth 实现，资料由 users，关系和黑名单由 social，头像由 media；设置只编排入口，不复制仓储逻辑。

## 11. 测试场景与验收条件

- [x] 游客看到登录入口且不请求私有资料，登录用户看到本人资料与隐私表单。
- [x] 简介与三项公开范围只提交变化字段，失败可恢复且服务端结果回写。
- [x] 本人关系与黑名单入口受鉴权，取消拉黑失败保留条目与请求 ID。
- [x] 登录终端读取、排序、隐私降级、当前终端保护、其他终端撤销及失败恢复正确。
- [ ] 密码和邮箱操作可恢复且状态正确。
- [x] 退出清本地会话且服务端失败保留安全后备；注销只用一次性账号人工验收。
- [ ] 开发信息准确且无敏感数据。

## 12. 已知限制和后续功能

当前不上传头像，不支持清空已有简介，也没有密码、邮箱、注销、关于或开发信息页面。登录终端只展示平台级信息，不提供设备命名；黑名单尚不与其他页面建立主动失效广播。不做暗色主题、动态实验开关和多账号管理；视觉设置在后续里程碑讨论。
