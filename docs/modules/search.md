# 搜索

状态：`planned`

## 1. 模块目标与非目标

提供主题、用户、正文三个按需加载 Tab。V1 不做搜索历史云同步或高级查询语法。

## 2. 用户角色与使用场景

游客和登录用户搜索自己可见的公开资源；权限由服务端结果决定。

## 3. 页面、入口和导航关系

底部搜索分支包含输入框和三个 Tab；结果分别进入主题、用户或精确楼层目标。

## 4. 用户操作流程

输入去首尾空白后提交；当前 Tab 立即请求，其他 Tab 首次切换才请求；关键词变化取消旧请求并重置各自 cursor。

## 5. API operationId 与生成类型

- `searchSearchThreads`、`searchSearchUsers`、`searchSearchPosts`、`threadSearchSearchPosts`。
- 主要生成类型：`SearchThreadResponseDto`、`SearchUserResponseDto`、`SearchPostResponseDto`。

## 6. 状态模型和数据流

每个 Tab 独立保存 query、分页和请求代次；只有最新代次可写回状态，避免慢响应覆盖新搜索。

## 7. 鉴权、权限和隐私规则

不缓存不可见资源；切换账号清空全部结果。搜索词首版不持久化，日志不记录完整敏感关键词。

## 8. 本地存储、缓存及失效规则

只保留当前进程 Tab 状态；返回前台不自动搜索，用户刷新才重新请求。

## 9. 加载、空数据、错误、重试和冲突状态

未输入、无结果、首次加载、加载更多和单 Tab 错误分别展示；取消请求不作为用户错误；无效 cursor 重载对应 Tab。

## 10. 跨模块约束

正文摘要按 Markdown 安全策略显示纯文本；楼层结果走精确导航；用户与主题卡片复用各模块展示模型。

## 11. 测试场景与验收条件

- [ ] 三个 Tab 按需加载且分页互不影响。
- [ ] 快速改词时旧响应不能覆盖新结果。
- [ ] 结果可导航到正确主题、楼层或用户。
- [ ] 空、错、取消、重试与无效 cursor 状态正确。

## 12. 已知限制和后续功能

不做语音搜索、云历史和全文高亮编辑；首版只高亮后端支持的安全片段。
