# 楼层与回复

状态：`in_progress`

## 1. 模块目标与非目标

0.3 当前切片实现所选子贴的升序楼层 Cursor 分页，以及每层由服务端内嵌的前五条楼中楼回复只读展示。独立楼中楼分页、回复、编辑、删除和精确导航后置；V1 不记录阅读进度。

## 2. 用户角色与使用场景

游客和登录用户阅读公开主题中的可见楼层与内嵌回复。登录成员发表内容、作者编辑以及有权限成员删除属于后续切片。

## 3. 页面、入口和导航关系

楼层列表位于主题详情当前选中的子贴正文下方；本轮只展示响应内嵌回复，不提供独立楼中楼页面。通知/搜索精确定位主题、子贴、楼层和回复在目标路由具备后接入。

## 4. 用户操作流程

选择子贴后加载第一页楼层，接近列表末尾或点击“加载更多”时沿不透明 cursor 继续，按楼层 ID 去重并保持 `floorNumber` 升序。每层直接展示服务端返回的前五条内嵌回复及总回复数；切换子贴使用该子贴独立的分页状态。当前不提供回复、发布、编辑或删除入口。

## 5. API operationId 与生成类型

- 当前只读切片：`postsFindFloors`。
- 主要生成类型：`PostsFindFloors200Response`、`FloorResponseDto`、`ReplyResponseDto`、`ApiPaginationMeta`。
- 后续独立阅读与写入：`postsFindReplies`、`postsFindById`、`postsCreate`、`postsUpsertBody`、`postsUpdate`、`postsRemove`。

## 6. 状态模型和数据流

当前选中子贴维护一个 `CursorPage<Floor>`、加载代次和局部错误；切换子贴清空旧页并重载，过期响应不得写入新选择。分页合并按楼层 ID 去重并维持升序，内嵌回复随楼层 DTO 一次映射，不建立独立分页状态。

## 7. 鉴权、权限和隐私规则

服务端是主题、子贴和楼层可见性的权威；私密父主题失权时清除详情与楼层缓存。游客不触发受保护写请求，已删除作者、媒体或未知回复目标只显示允许的安全占位信息。

## 8. 本地存储、缓存及失效规则

本轮楼层只保留当前详情页的进程内状态，不写 Drift。切换子贴、切号、权限变化、主题重新加载或子贴失效时清除当前楼层页。

## 9. 加载、空数据、错误、重试和冲突状态

首屏加载、无楼层、首屏错误、分页局部错误、加载到底和内嵌回复为空分别展示明确状态。`40007 INVALID_CURSOR` 清空当前子贴楼层并从第一页重载；其他子贴分页不受影响。精确定位、版本 409 和幂等重试由后续读写切片处理。

## 10. 跨模块约束

楼层与内嵌回复复用主题详情的 Markdown v2 只读组件、媒体降级和未知节点策略；回复层级视觉上最多两层。未来通知导航不依赖本地页码猜测。

## 11. 测试场景与验收条件

- [ ] 所选子贴楼层按 `floorNumber` 升序分页，自动/显式加载更多均不重复、不乱序。
- [ ] 切换子贴时正文与楼层源一致，旧 cursor、到底、局部错误和过期响应不会污染新选择。
- [ ] 每层最多展示响应中的前五条内嵌回复，并使用 `_count.replies` 表达尚有更多回复但不提供伪入口。
- [ ] 首屏加载、空、错、重试、分页错误、到底及 `40007` 重载状态正确。
- [ ] 楼层和回复 Markdown、长内容、失效图片、已注销作者及未知枚举安全降级。

## 12. 已知限制和后续功能

当前不做独立楼中楼分页、精确目标定位、创建/回复/编辑/删除、离线发帖、离线阅读或阅读进度；大楼层性能在 0.7 专项验收。
