# 楼层与回复

状态：`planned`

## 1. 模块目标与非目标

实现升序楼层、楼中楼、回复、编辑、删除和精确导航。V1 不记录阅读进度。

## 2. 用户角色与使用场景

游客阅读可见楼层；登录成员发表楼层或回复；作者和有权限的成员编辑或删除。

## 3. 页面、入口和导航关系

楼层列表位于选中子贴下；楼中楼可展开或进入详情；通知/搜索可定位主题、子贴、楼层和回复。

## 4. 用户操作流程

升序分页加载，点击回复预填目标；发布时复用稳定请求 ID；编辑携带 version；删除二次确认后刷新相关计数。

## 5. API operationId 与生成类型

- `postsFindFloors`、`postsFindReplies`、`postsFindById`。
- `postsCreate`、`postsUpsertBody`、`postsUpdate`、`postsRemove`。
- 主要生成类型：`FloorResponseDto`、`ReplyResponseDto`、`PostDetailResponseDto`、`CreatePostDto`。

## 6. 状态模型和数据流

每个子贴独立 `CursorPage`；楼中楼按楼层 ID 分页；精确导航先解析目标再确保相邻页加载和滚动定位。

## 7. 鉴权、权限和隐私规则

服务端是可见性与编辑权限权威；私密父主题失权时清缓存。已删除正文只显示允许的占位信息。

## 8. 本地存储、缓存及失效规则

发布快照与未确认操作存 Drift；成功确认后清理。楼层只在进程内按子贴缓存，切号或权限变化失效。

## 9. 加载、空数据、错误、重试和冲突状态

无楼层、回复为空、目标已删除和精确定位失败有明确提示。`40007` 重载；版本 409 保留编辑；超时重试复用请求 ID。

## 10. 跨模块约束

编辑器负责 Markdown、提及与骰子；媒体只插入完成资源；通知导航不依赖本地页码猜测。

## 11. 测试场景与验收条件

- [ ] 升序楼层和楼中楼分页不重复、不乱序。
- [ ] 创建、回复、编辑、删除与恢复后状态正确。
- [ ] 搜索/通知能精确定位目标或解释目标失效。
- [ ] 弱网超时和版本冲突不产生重复内容、不丢正文。

## 12. 已知限制和后续功能

不做离线发帖、离线阅读或阅读进度；大楼层性能在 0.7 专项验收。
